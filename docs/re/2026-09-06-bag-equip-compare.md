# 背包装备详情：同部位对比（2026-09-06）

## 需求

背包打开装备详情时，若身上同部位已有穿戴，在属性行右侧显示与当前穿戴的差值：

| 关系 | 显示 | 颜色 |
|------|------|------|
| 相同 | `=` | 白 |
| 高于穿戴 | `+m` | 红 `0xff2020` |
| 低于穿戴 | `-n` | 绿 `0x00ff00` |

对比字段：等级、强化、力量/敏捷/智慧、物攻/护甲（含强化 M(L)）、躲闪/命中/暴击/抗性/气血/法力；**强化附加/洗练四档**（`+4/+8/+12/+16`）同档对比。不对比类型/职业/耐久。

洗练档规则：

| 情况 | 显示 |
|------|------|
| 同属性类型且同 flat/% | `=` / `+m` / `-n`（色同上） |
| 属性类型或 % 标记不同 | 黄字穿戴档 `属性名+value`（如 `力量+120` / `气血+5%`） |
| 穿戴未解锁该档 | 按对方为 0 → 红字 `+value` |

## 实现

- `PixiJS_web/src/ui/equipDetail.ts`：`equipEffectiveStats` / `buildEquipCompareMarks`
- `PixiJS_web/src/ui/SystemPanel.ts`：`drawBagEquipDetail` 右侧 `addAttrTextRight`；`setWorn` 在背包详情打开时重绘
- `PixiJS_web/src/main.ts`：打开背包时额外 `openWornEquipment()`（不清空旧快照，避免闪一下无对比）

## 验证

1. 身上已穿武器，背包打开另一件武器详情 → 右侧出现 `=`/`+m`/`-n`，高低着色正确。
2. 同部位空槽 → 无对比列。
3. 先开详情再等穿戴回包 → 对比自动出现（`setWorn` 重绘）。
4. 物攻/护甲含强化增量：对比用 base+delta 有效值，与左侧黄字语义一致。
5. 双方强化≥4：洗练/默认档行右侧也有对比；同类型比数值，不同类型显示穿戴方 `属性名+value`；红字洗练档参与数值对比。
6. 背包件已解锁 +8、穿戴仅 +4 → +8 行显示红字 `+value`（对方未解锁）。
