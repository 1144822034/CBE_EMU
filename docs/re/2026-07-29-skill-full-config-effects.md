# 2026-07-29 技能配置完整落地（debuff / 沉默 / DoT / 复活）

## 触发

此前进攻技能只结算 `|生命变化| + 力/敏/智系数`，说明与 DSH 中的附带效果未接：

- 伤害 + 敌方属性降低（雷震八方 / 破甲烈刃 / 天火熔身 / 血祭魔瞳）
- 沉默（神堂静默，`效果=1`）
- 持续毒伤（毒入膏肓，`时效` + 负生命、无属性列）
- 复活（尸鬼召唤，`效果=3`）
- 驱散（天眼通明，`效果=2`：清目标异常；仍结算其负生命伤害）

## 证据

`bin/JHOnlineData/skill.dsh` 列：

| 列 | 名 | 用法 |
| --- | --- | --- |
| 9 | 时效 | 回合数 |
| 10 | 目标指向 | 0 己 / 1 单友 / 2 友群 / 3 单敌 / 4 敌群 |
| 14 | 生命变化 | 伤害/治疗底 |
| 16–24 | 力…抗性变化 | 己方 buff 或敌方 debuff |
| 25 | 效果 | 0 普通 / 1 沉默 / 2 驱散 / 3 复活 |
| 29–31 | 力/敏/智系数 | `(属性×系数)/100` |

系数列映射与样例（万剑诛仙力 50、瞬影敏 50、绯炎智 110）已核对正确。

## 实现

- 解析 `效果` → `skill->effectKind`
- 每敌槽 `g_mockBattleEnemyAilments[3]`：stat debuff / silenceRounds / DoT
- 命中后挂 debuff；破甲等降低怪防御参与后续伤害
- 神堂静默：挂沉默；切磋与 **PvE** 沉默目标只能普攻（怪不可回血/放技能，见
  `2026-08-01-pve-silence-blocks-monster-skill.md`）
- 毒入膏肓：首跳当次伤害，余 `时效-1` 回合在 round advance 跳伤
- 尸鬼召唤：可复活死亡队友（队伍）
- 天眼通明：伤害后清空目标异常

## 仍标 unresolved

- 轻身术等「说明」写攻击力 +%，数值在 `躲闪变化` 列：按列落地（敏+躲闪），不以说明覆盖列
- DoT 跳伤未单独写 type-1 子动作（只改 HP）；若需毒伤飘字需再取证
- 法力变化 / 耗费金钱 / 使用条件列当前全表为 0 或未进战斗权威路径

## 验证

- `make -j2` 通过
- 建议复测：破甲后怪承伤上升；神堂静默后切磋只能普攻；毒入膏肓多回合掉血；尸鬼召唤拉起队友
