# 组队遇怪时 0 血队员卡住且无死亡提示

## 压缩结论

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 队长有血遇怪后，同场景 0 血队友卡住、不能操作、也不出死亡提示 | `team_collect_battle_members` 只按同场景收编，把地图死亡队员也写入 `pendingTeamBattleSerial` 并投递 `4/5`；对方进入 Battle.cbm 后 HP=0 不进 `alive_mask`，既无出手回合也无战斗内死亡提示链 | 收编/开战时跳过 durable+online 均为 0 的队员；pending 投递再挡一层。仅剩队长存活时回落单人开战 |

## 契约

- 地图死亡（HP=0）的队员不得被拉进本场 Battle.cbm。
- 组队开战名单只含可战斗席位；`alive_mask` 仍按本场 `battleMemberHp!=0` 且未 `leftMask`。
- 战斗中途死亡仍走既有死亡提示 / 复活石 / `leftMask` 路径，与本修复无关。

## 验证

重启服务。

1. 两人组队，一人地图 HP=0，队长遇怪：0 血方留在场景可操作（可去商城/复活），不进战斗 UI；日志 `team_battle_skip_dead_member`；队长按存活人数开战（仅自己则单人）。
2. 两人都有血：组队战斗行为不变。
3. 战斗中途死亡：仍应有死亡提示，不应再被本修复误伤。
