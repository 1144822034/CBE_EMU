# 查看附近玩家补上资料行

phase: nearby-player-info-profile
status: fixed

## 触发

周围玩家 / 好友菜单点「玩家信息」。Pixi 只列出 `29/4` 穿戴装备，没有名称、称号、等级、职业、配偶、帮派。

## 根因

2026-09-19 为避开 `29/4` 宝石孔尾把后续装备行读丢，暂时不再请求 `10/2`。装备解析修好之后，资料行没有接回来。

当时的 `10/2` 也只有三行：姓名、等级+职业（文案仍是战士/刺客/法师）、帮派+性别。称号和配偶没有字段。称号实际在在线会话 `onlineRoleTitle`（与属性面板同一来源）。配偶在角色 `spouse_name`，进场景时没有镜像到会话，玩家信息响应读不到。

## 修改

- `10/2` `playerinfo` 为 4 行，`fdegree` 为最后一行：姓名、称号、`等级：<n>级　职业：<天机/幻剑/鬼道>`、配偶、帮派。`num=4`。CBE `HandleFactionDegreeResponse` 仍按 `num` 逐条显示再追加 `fdegree`。
- 进场景时把配偶名写入 `onlineSpouseName`；缔结姻缘成功时双方会话立即更新。
- 帮派仍按账号+角色 id 查 `guild_members`；角色 id 用 `onlineRoleId`，查不到再用会话里的帮派名。
- Pixi「查看玩家信息」同时拉 `10/2` 和 `29/4`，资料行下面再列装备。单独的「查看装备」仍只列装备。

## 验证

- `src/main.c` 已编过（`make -j2 server` 的编译步骤通过）。链接 `bin/jh-online-server.exe` 时文件被正在运行的进程占用，未能替换正在跑的服务端。
- Pixi `tsc --noEmit` 通过。
- 未在运行中的客户端上点开附近玩家卡片。重启服务端并重新进场景后，卡片应出现姓名、称号、等级、职业、配偶、帮派，下面仍是装备列表。

## 仍未知

已经在线、且服务端热更新前就进过场景的会话，要等下一次进场景刷新才会带上配偶名。重登或重新进场景后正常。
