# 后台统一单页面外壳

## 目标

后台各业务页由同一个固定的标题与管理导航外壳承载。切换账号、内容、任务、怪物、商品、
宝箱、更新、服务器和风险角色等栏目时，只替换中间内容区；顶部导航不再随着页面模板改变
样式或重新创建。

## 实现边界

- 公共 `admin.js` 在认证后的 `main.wrap` 中保留标题和导航，并把各页面原先位于导航后的内容
  收拢到 `#admin-spa-content`。该锚点使用 `display: contents`，不额外创建布局盒子，页面原有的
  `.grid`、`.layout`、`.update-grid` 仍直接参与 `.wrap` 的弹性布局和内部滚动。
- 标题统一为“江湖 OL 后台管理”，导航项由同一份栏目定义生成，并用固定的
  `#admin-spa-tabs` 样式覆盖各页面历史遗留的局部标签样式。
- 跨栏目导航经异步请求取得服务端已渲染页面，只替换内容区并更新地址栏历史；返回/前进也
  按相同方式恢复内容区。
- 切换时同时附带目标页面 `<head>` 内的专属样式，避免内容页沿用上一栏目样式、退回浏览器
  默认链接和表单外观。
- 怪物、任务的既有细粒度请求继续保留；其余后台表单优先只替换所在 `data-admin-detail` 编辑
  区。没有独立编辑区的页面才替换当前栏目内容区，固定顶部不刷新。
- 登录、退出、文件下载、账号搜索和原生浏览器校验仍走各自正确的流程，不被单页面拦截层
  劫持。

## 缓存

后台脚本版本升为 `admin.js?v=20260813-5`。服务端重启后浏览器会重新取得统一外壳逻辑，避免
继续使用旧脚本造成页面仍整页跳转。
