# 怪物管理目录遗漏 SCE 战斗 Actor（2026-07-26）

## 触发条件

后台「怪物管理」左侧目录缺很多常见怪；用户举例「毒泥怪这些」。

## 数据链路与证据

后台只枚举静态 `g_vm_net_mock_monster_entries[]`（`vm_net_mock_monster_admin_list`）。
MySQL `server_monsters` 只能覆盖目录内已有 ID，不能补出目录外怪物。

交叉核对 `web/fs/JHOnlineData`：

| 来源 | 唯一非零战斗 Actor / ID | 说明 |
| --- | ---: | --- |
| `automonster.dsh` | 73 | 自动刷怪声明 |
| 静态目录（修复前） | 80 | automonster ∪ 任务专属 |
| 上述场景 SCE 解压后的战斗 Actor | 90 | `kind=3` + `field 14` actor id |

`#105 毒泥怪` **已在**静态目录与 `automonster.dsh`（桃花岛 `_01`）中；SCE 解码后可解析到
`e_mucusP.actor` / 名称「毒泥怪」。按名称搜不到时，优先怀疑名称标签未加载或未滚动到
`#105`，而不是目录缺这一项。

真正缺目录的是 **SCE 有、automonster/静态目录无** 的 11 个 ID：

| ID | SCE 名称 | 同场景 automonster 声明（等级参考） |
| ---: | --- | --- |
| 12 | 猪王独牙 | `1`（Lv.6） |
| 21 | 炽热火灵 | `31`/`78` |
| 24 | 镇狱明王 | `69` |
| 26 | 深渊鬼王 | `75`/`107` |
| 72 | 长生将军 | `25` |
| 80 | 千年岩精 | `22`/`36` |
| 85 | 绿焰怪 | `86` |
| 88 | 小龙女 | `86` |
| 90 | 拜月教主 | `87` |
| 100 | 尸鬼王 | `99` |
| 102 | 云石鬼 | `101` |

第一次偏离：静态目录契约写成「automonster ∪ 任务击杀目标」，没有覆盖「场景里实际
存在、但未写入 automonster 三槽」的战斗 Actor。后台因此无法编辑这些 ID 的属性/掉落。

名称加载器此前只在「当前 automonster 行声明了该 Actor」时写入 SCE 名，以保护任务专属
目标不被同场景其它 Actor 污染。上述 11 个 ID 即使补进目录，在旧规则下仍会显示「未命名」。

## 修复

1. 将上述 11 个 ID 加入 `g_vm_net_mock_monster_entries[]`。初始等级按同场景
   automonster 邻居建模，类型按名称归类；**不是**已恢复的原始服务端数值表，可在后台改。
2. 名称加载：目录内、且**非**任务专属 ID 的 SCE 战斗 Actor，允许在 displayName 仍空时
   写入名称与首次场景；任务专属集合仍只走 `task.dsh` 标签，避免再次出现「火腹蛇」类污染。

修复后目录应为 **91** 项；SCE 战斗 Actor 集合应被静态目录覆盖。

## 验证结果

1. 静态目录复核为 **91** 个唯一 ID；原先缺失的 11 个 SCE Actor 与 `#105` 均在目录中。
2. 离线复扫 automonster 场景 SCE：上述 11 个 ID 均可解出中文显示名；`#105` 仍为「毒泥怪」。
3. `make -j2` 通过并已用新 `bin/jh-online-server.exe` 重启；`http://127.0.0.1:19091/healthz` 返回 200。
4. 正式后台登录密码与当前库不一致（默认 `123456` 返回 401），未在本机完成带 Cookie 的 HTML 复测；
   请登录后打开 `/?tab=monsters`，确认目录计数为 91，搜索「毒泥怪」「猪王独牙」可命中。
