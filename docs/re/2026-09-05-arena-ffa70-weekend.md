# 周末 70 级三职业大乱斗（日程键 77）

日期：2026-09-05  
范围：`mock_server_arena.c`、`web_admin_arena.inc.c`、Pixi `ArenaPanel` / `protocolArena` / `main.ts`

## 需求

- 周末可开 **70 级三职业大乱斗**
- 地图仍用 **70 级图**（`基准场景+"70"`），不分职业分图
- 仅 **70 级+** 可进；其它机制对齐现有 70 级比武（计分、回合加深、连杀播报/称号、禁辅助等）
- **奖励单独配置**，不与分职业 70 榜共用

## 契约

| 项 | 行为 |
|----|------|
| 日程键 | `weekday_brackets` 取 **77**（`VM_MOCK_ARENA_BRACKET_FFA70`） |
| 进场资格 | `level >= 70`（与 70 档相同） |
| 场地 | 全员 `scene_for_job(3)` → 基准+`70` |
| 互见 / 匹配 / 加赛 | 忽略 `job`，同 bracket=77 一池 |
| 结算排名 | 全场一张榜；冠亚季称号写入 `server_arena_titles` 的 **job=0, bracket=77** |
| 领奖 | `find_reward(0, 77, rankPos)` |
| 排行协议 | 请求 bracket=77 时 job 强制按 0 处理；Pixi 段位页签「乱斗」 |

普通 10/50/70 分职业日行为不变。

## 后台

- 每日开放段位增加选项「70大乱斗(三职业同场)」
- 奖励：职业填 **0**，段位填 **77**，名次 1–5
- 新装默认 `77,70,50,10,70,50,77`；已有库需在后台改周六/日并保存，或执行 `server/mysql/migrate_add_arena_ffa70.sql` 中的可选 UPDATE
