# 经验卡叠加与掉线持久化

## 需求

1. 已有**同倍率**经验卡效果时仍允许再使用同种卡（续时长），异倍率则提示“同类效果已生效”并拒绝。
2. 掉线 / 重登不清经验卡状态；**掉线期间不计时**（见 `2026-07-30-exp-card-pause-offline.md`）。
3. 剩余时长上限 **8 小时**：若本次使用后剩余将超过 8 小时则拒绝并提示。
4. 左上角小图标与战斗加成一致显示（依赖 `7/31` 非空 `expinfo`）。

## 规则

| 情况 | 行为 |
| --- | --- |
| 无激活经验卡 | `expires = now + 60min`，倍率为本卡 2/4/10/30 |
| 已有**同倍率**经验卡再使用 | 在剩余结束时刻上再加 60 分钟；倍率与 `item_id` 保持当前激活卡 |
| 同种续时后剩余将 **> 8 小时** | 拒绝，不扣物品；提示「经验卡持续时间已达上限（8小时），请等待时间减少后再使用。」 |
| 已有**异倍率**经验卡再使用 | 拒绝，不扣物品；提示「同类效果已生效，请等待结束后再使用。」 |
| 掉线 | 冻结剩余到 `paused_remaining_sec`，`expires_unix=0`；重登再恢复墙钟结束时刻（离线不计时） |
| 图标 UI | 激活时下发 `7/31 {expinfo}`（含剩余时间）；过期下发 `7/32 {expcard=0}` |
| 到期 | 在线且 `expires_unix <= now`（且未暂停）时 DELETE 行，并走既有 `7/31`+`7/32{expcard=0}` |

战斗心得 / 大力丸等其它时效道具仍拒绝二次使用（心得自身可续时，见心得文档），不因经验卡规则改动。

## 实现

- `VM_NET_MOCK_EXP_CARD_MAX_REMAINING_SEC = 8*3600`
- `vm_net_mock_role_consume_backpack_item_with_timed_effect`：
  - 同倍率才 stack；日志 `mock_exp_card_stacked`
  - 异倍率：`mock_exp_card_rejected_different_type`
  - 续时后将超过 8h：`mock_exp_card_rejected_max_duration`
- 掉线暂停 / 上线恢复见 `2026-07-30-exp-card-pause-offline.md`
- 自定义卡 `845` 的通用 `7/1` 路径使用同一拒绝文案

## 变更（2026-08-01）

1. 任意经验卡互续 + `max` 倍率 → 仅同倍率可续，异倍率拒绝。
2. 增加剩余时长上限 8 小时；叠加后将超过则拒绝（离线不计时规则保持不变）。
