# 后台 SCE 场景地点标题

## 范围

“游戏内容管理 → SCE 场景”的文件列表不再把资源文件名作为主标题。列表读取当前服务端实际可加载的 SCE 数据：第一个有效命名传送点的字段 `0x16`（地点显示名称）为主标题；精确 SCE 文件名保留为副标题和资源键。

例如 `00_蓬莱仙岛01.sce` 的字段 `0x16` 为“蓬莱仙岛-十二城”，因此列表显示为：

```text
蓬莱仙岛-十二城
00_蓬莱仙岛01.sce
```

## 解析与失败边界

地点标题复用后台现有的命名传送点解析器，仅读取已验证的 SCE 记录；不会修改 SCE、地图、传送点或客户端状态。若某个 SCE 没有可解析的非空地点字段，列表回退为资源文件名，避免隐藏或伪造场景信息。

搜索键包含地点标题和文件名，因此既能按“蓬莱仙岛-十二城”检索，也能按精确资源键检索。

## 回归

`scripts/admin-sce-location-title-regression.c` 使用仓库内的资源夹具验证：示例 SCE 的地点字段解析为“蓬莱仙岛-十二城”，并确认后台标记了主标题、副标题及包含地点名称的搜索键。测试不启动服务、不连接数据库、不写入资源。
