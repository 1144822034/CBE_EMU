# 首领怪物装备掉落 Excel 导出（2026-08-14）

## 目标

后台“怪物管理”提供一个仅管理员会话可访问的下载入口，导出当前首领怪物的**装备**掉落与
每条掉落的独立概率，供运营整理掉落表。

## 权威数据与边界

1. 首领身份使用 `vm_net_mock_monster_admin_list()` 返回的当前怪物目录中
   `family == VM_NET_MOCK_MONSTER_BOSS` 的行。该目录在首次加载时由基础目录与真实 SCE2
   `kind=3` 场景战斗节点合并，不以 `automonster.dsh` 误当成全部首领名单。
2. 掉落使用同一管理行的 `drops[]`。它已合并 MySQL `server_monster_drops` 覆盖；每条记录
   都是一次独立概率投掷，不能把多个概率相加或重新归一化。
3. 仅导出物品目录中 `isEquip` 为真的掉落。物品名称、品质与需求等级仍取
   `item.dsh/equip.dsh` 的服务端目录，不读取角色背包实例，也不把强化等级写入表中。
4. 位置以怪物目录记录的首个场景为准。区域从场景资源名的区域段提取，位置保留规范化的
   场景标识；没有原生场景标签的首领会明确标为“特殊挑战”，不会虚构地图位置。

## 文件与版式契约

- 下载端点：`GET /admin-418yz6/monster-boss-drops.xlsx`。
- 与所有后台页面共用 `cbe_admin` 会话校验；未登录请求只会跳转到后台登录页。
- 输出真正的 `.xlsx`（ZIP/Office Open XML），不是把 HTML 或 CSV 改扩展名。
- 工作表列为：`区域`、`位置`、`BOSS`、`掉落装备`、`概率`。
- 同一场景中的同一首领占连续行；区域、位置和 BOSS 单元格纵向合并，装备与概率逐条列出。
  表头及间隔行带颜色和冻结首行，便于直接在手机或桌面 Excel 打开后筛选。

## 验证计划

1. 构建后确认下载响应使用 Excel MIME、附件文件名与标准 XLSX 文件头 `PK`。
2. 解压工作簿，确认必须的 OOXML 部件、表头、首领筛选和 `server_monster_drops` 的多条独立
   概率均存在。
3. 人工在后台点击“导出首领掉落”后用 Excel 打开，确认同一 BOSS 的多件装备呈连续行且
   概率与怪物编辑页一致。
