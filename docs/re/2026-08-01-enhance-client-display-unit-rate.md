# 强化界面本地成功率对齐 /3 阶梯（2026-08-01）

## 目标

客户端选玄晶时显示与服务端一致：

| 相对目标等级 | 显示 |
| --- | ---: |
| ≥ 目标 | 100% |
| 小 1 级 | 33% |
| 小 2 级 | 11% |
| 小 3 级 | 3% |

例：`+5→+6`：≥六级 100%，五级 33%，四级 11%，三级 3%。

## 根因

客户端本地公式：`min(100, Σpower × 100 / required[curlevel])`。

旧紧凑表 `power=tier×100`、`required=L×250` 使同级固定约 40%、目标级约 40%–48%。
全局指数表虽能对齐比例，但 `required(+13)` 过大，会把可用上限截到 12。

## 修改

`29/1` 按**当前装备强化等级 L** 编码小数值表（最大 100，无截断风险）：

```text
required[any] = 100
power[tier]   = unit_rate(L, tier)   // 100 / 33 / 11 / 3 …
```

本地显示百分比 = `unit_rate`。铜币仍用紧凑曲线 `+0→100`、`+N→N×250`，与显示表分离。

`29/3` 成功后追加一次 `29/1`（`curlevel=新等级`），刷新表以免连升时仍用旧 `power[]`。

`29/2`/`29/3` 掷骰仍走 `crystal_unit_rate()`。
