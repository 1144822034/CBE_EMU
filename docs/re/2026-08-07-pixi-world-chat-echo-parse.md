# Pixi 世界消息发送无回显

## 现象

世界频道发送后界面无新消息（服务端已实现 `1/3/3 type=0` 回显）。

## 根因

`parseChatNotices` 把 `chatinfo` 字段值的 **BE16 长度高字节** 当成消息条数：

- `put_object_blob` → 字段 raw = `BE16(dataLen) + [u8 count][seq…]`
- 小包时 `raw[0]===0` → `count=0` → 永远解析不出行

世界通道无客户端本地插入，只依赖该回显，故表现为「没反应」。

## 修改

先剥 `BE16` 再读 `count` 与 seq 行；名字/正文去尾 `\0`。

## 验证

世界频道发一句 → HUD / 聊天面板出现黄字 `[世]角色名: …`。
