# 可使用道具效果核对（2026-08-11）

## 结论

本次按客户端实际协议将“效果”分为两类：战斗中的 `WT 4/6 actioninfo`
Eidolon 特效，和场景/状态类道具的数值或时效效果。两者不能混用。

- 所有可在战斗中恢复 HP 或 MP 的物品均已使用 `eidolon.dsh` index 13 的
  `f_renew1.actor`（`回复.gif`）。这包括 `301..305`、`321..325`、
  `341..343`、`802` 和 `803`；MP-only 逍遥壶不再错误使用血滴特效。
- `江湖OL.CBE:0x01033544` 的普通场景 `WT 7/1` parser 不读取 Actor/effect
  字段，只读取 `result/type/id`，再经 `7/7`/`7/11` 刷新物品和数值。因此
  场景使用药品没有缺失“播放特效”的协议字段，服务端不能在该回包臆造战斗 Actor。
- 经验卡 `809..811` 的 2/4/10 倍、`525..531` 与 `820..826` 的攻防百分比、
  修炼丹 `827` 的一小时修炼时间，以及复活石、扩容、宝箱等各自的专用流程，均走
  对应客户端专用请求而非泛用 `7/1`。

## 证据与回归

- 已按 `binary_name` 选择 IDA 的 `江湖OL.CBE` 与 `mmBattleMstarWqvga.cbm` 实例。
  `Battle:0x6EB0` 证明 action type 1/2 都读取 `effect`；type 2 对 802/803 有
  原生的库存扣减例外。`CBE:0x01033544` 证明场景 `7/1` 无 Actor 字段。
- `web/fs/JHOnlineData/item.dsh` 给出 15 条战斗恢复记录，`eidolon.dsh` index 13
  为 `f_renew1.actor`，其 actor manifest 引用 `回复.gif`。

  条恢复记录均选择同一恢复 Actor，且其中恰有两条蓄量壶记录；测试不启动服务端、客户端
  或 MySQL。
