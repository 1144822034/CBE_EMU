# 跑环任务描述澄清（2026-08-28）

## 需求

1. 提交药品：明确「一组」对应多少个  
2. 击杀怪物/Boss：按场次提示，并备注地图  
3. 拜访 NPC：注明地图，以及对话即完成  
4. 收集材料：显示材料名 + 地图·怪物掉落（勿用 `#编号`）

## 契约与实现

权威描述由服务端 `vm_mock_ring_format_desc`（`mock_server_activities.c`）生成，经 WT47/1 `desc` 下发；Pixi `RingQuestPanel` 只展示。

| 类型 | 描述示例 | 进度/消耗 |
|------|----------|-----------|
| 提交药品 | `提交2组小回春散(每组10个,共20个)，药师处购买` | `targetCount`=组数；校验/扣除 `组数×10` |
| 击杀小怪 | `击杀12场黑熊(蜀山南门)` | 战斗胜利结算 +1 场；目标 **10–30 场**；**组队参战全员各计**（匹配目标时） |
| 击杀Boss | `击杀1场赤练仙子(场景名)` | 同上，目标通常 1 场；组队参战同样共享 |
| 击杀玩家 | `切磋战胜1名天机(20-49级)玩家` | **友好切磋**胜利计进度（强制PK/擂台/赌战不计）；须匹配职业(天机/幻剑/鬼道)+等级段；按胜者账号落库 |
| 拜访 | `拜访蜀山铁匠(对话即可完成)` | `on_npc_talk` 名称包含关键词即完成 |
| 收集 | `收集3个黑猪獠牙，蜀山·黑熊掉落` | 背包数量 ≥ 目标；雁门材料示 `雁门关打怪掉落` |
| 世界真心话 | `世界真心话：世界频道发送「…」(用小喇叭，发完可提交)` | 世界频道原文发送后可提交；见 `2026-09-01-ring-quest-world-truth.md` |

材料名：优先 `item.dsh`/商城目录；旧雁门 id 850/851 映射为 木材/石料（正式默认改为 3/5）。  
掉落提示：短地图名 + `·` + 怪物显示名；无名字时回退战斗外观名。

## 验证

- 重新接环后看描述是否含「每组10个」/「场」/地图/`对话即可完成`  
- 收集任务：名称非 `#数字`，并含 `地图·怪物` 或 `雁门关打怪`  
- 药品：背包不足 组×10 时提交失败；够则扣对应件数  
- 击杀：一场胜利进度 +1，与场内怪数量无关；**组队战斗**时参战席各自按账号落库（见 `2026-08-31-ring-quest-team-kill-progress.md`）  
- 拜访：与目标 NPC 对话后进度变为已完成，回跑环使提交  
- **地图追踪（2026-08-31）**：进行中的环会出现在左侧任务追踪首行（见 `2026-08-31-ring-quest-tracker.md`）  
- **击杀筛选（2026-08-29）**：`vm_mock_ring_pick_monster_id` 要求 `firstScene` 能解析出可读地图名；世界Boss 配置 `monsterId` 不进池；空池时该次环改为拜访
- **地图溯源收紧（2026-09-01）**：`firstScene` 为 `task.dsh#N` 等非地图来源时（后台「出现位置／来源」），击杀与收集环均不分配；`resolve_map_label` 兜底把 `task.dsh` 当成标签的路径已排除

## 风险

- **已接取未交的旧环**仍用旧描述与旧药品数量（组=1 个）；需放弃后重接或等自然结算  
- 拜访地图为常见落点提示，同名 NPC 可能出现在其他图；完成条件仍是对话匹配关键词  
- 收集：若怪物表缺 `displayName`/`firstScene`，提示会变短；后台补全怪物管理更佳  
- 击杀池过窄时会更多抽到拜访；应在怪物管理补全 `source_label`/场景显示名  
- **后台清环（2026-08-29）**：账号管理 → 角色操作「移除跑环任务」清当日 `task_active`（保留环数）；在线同角色会清进程内环运行时
