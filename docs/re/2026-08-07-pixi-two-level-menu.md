# Pixi 二级场景菜单

## 变更

将原扁平菜单改为对齐 CBE 卷轴样式的二级菜单（`MenuScreen`）：

| 一级 | 行为 |
|------|------|
| 江湖商城 | 直接打开商城（`1/14` 等既有路径） |
| 玩家信息 | 二级：属性 / 背包 / 装备 / 术 / 称号 |
| 帮派家族 | 既有帮派 Hub |
| 社交聊天 | 二级：周围玩家 / 好友 / 聊天信息 / 排行榜 |
| 系统设置 | 二级：脱离卡死 / 离开游戏 / 离开队伍 / 快速修理 / 挂机战斗 |

已移除主菜单「强化」（背包装备详情仍保留强化/重铸）。

## 新接线协议

| 功能 | 请求 | 响应要点 |
|------|------|----------|
| 称号列表 | `1/23/1` | `designationinfo` 为 put_object_entry 流（无外层 BE16） |
| 装备称号 | `1/23/3 {type=id}` | `result` + 可选 `23/2` 头顶更新 |
| 排行榜 | `1/23/7 {type,pageIndex}` | `orderlist` / `topplayerinfo` entry 流 |
| 快速修理报价 | `1/7/29 {type=1}` | `repairnum` / `coolmoney` |
| 快速修理确认 | `1/7/13` | `result=1` 成功，`2` 酷宝不足 |
| 挂机 | `2/10 Type=2` | 既有；开战时用所选 `operate`（普攻 0 / 技能 id+2） |

聊天信息：无独立历史 WT；面板展示本地 HUD 历史，发送仍走 `3/1`。

## 验证

- `npx tsc --noEmit`（PixiJS_web）通过。
- 手工：菜单 L1→L2 返回、商城直开、周围玩家组队邀请、称号装备后头顶、排行榜切页签、快速修理确认、挂机选技能后进战自动释放。
