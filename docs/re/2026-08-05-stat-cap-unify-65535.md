# 2026-08-05 角色属性封顶统一为 65535

## 触发

产品要求：原先战斗衍生属性 **9999**、职业基础主属性 **999** 的硬顶，全部改为 **65535**（与客户端 actor halfword / u16 一致）。

## 修改前契约

| 字段 | 旧上限 |
|------|--------|
| 职业等级基础力/敏/智/耐（`vm_net_mock_role_derived_attr`） | 999 |
| maxHp / maxMp / attack / defense / hit / dodge / crit / resist | 9999 |
| 战斗 buff / 怪物 ailment 加减后的上述战斗属性 | 9999 |
| 装备后力/敏/智/耐/魅 | 已是 65535 |

## 修改点

- `src/server/mock_server_role.c`：`vm_net_mock_role_derived_attr`、`vm_net_mock_role_build_player_stats`、`vm_net_mock_battle_apply_signed_stat_change` 默认值与战斗 modifier / ailment 路径
- `src/server/mock_server_battle.c`：怪物 debuff 后 defense / attack / hit / resist
- 模型文档：`2026-06-28-player-attribute-model.md` 等 attack cap 表述同步为 65535

## 验证

- `make -j2`
- 高属性角色：物攻/血蓝可超过 9999；职业基础主属性可超过 999（加装备后仍 ≤65535）

## 风险

客户端若对面板数字宽度或战斗飘字有显示截断，高值时可能只影响展示；战斗结算按服务端 u16 封顶。
