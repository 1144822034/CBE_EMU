# 装备出售凭证：按品质出售

> **2026-09-29**：修理 NPC 根对话带 `OPEN_EQUIP_SELL` 时，勿在外层注入批量选项；
> 「出售背包全部装备」「按品质出售」仅出现在进入装备出售后的内层对话框。

## 需求

装备出售凭证(839)对话框在「出售背包全部装备」后增加「按品质出售」，仅出售背包中对应品质的未强化装备。

## 行为

| 选项 | 动作 |
|------|------|
| 出售背包全部装备 | 既有：全部未强化 |
| 按品质出售 | 选 白/绿/青/紫/红 → 确认 → 按品质过滤批量 `SELL_BASE` |

- 品质：0白 / 1绿 / 2青 / 3紫 / 4红（精确匹配）
- 仍跳过已强化；售出后不可找回
- 客户端 action：`320` 品质菜单、`321` 确认入口、`322` 确认出售；取消复用 `295`
- `296`/`297` 是提炼确认，不能复用（见 `2026-09-19-equip-sell-quality-action-collision.md`）

## 修改

- `protocolExtras.ts`：`augmentEquipSellDialog` 追加选项；品质匹配 helper
- `GameSession.ts`：`sellUnenhancedBagEquips({ quality })`
- `main.ts`：对话框分支

## 验证

1. 使用 839 → 出售对话框末尾见「出售背包全部装备」「按品质出售」
2. 按品质出售 → 白装 → 确认 → tip「已出售 N 件未强化白装」；仅白装消失
3. 强化装、其他品质装保留；铜币增加
4. 「出售背包全部装备」与梦境徽章 / 星空石流程不受影响
