# 强化成功率：目标级 100% / 当前级及以下 ÷3 取整（2026-08-01）

> **取代** `2026-07-31-enhance-same-tier-rate-100.md` 中的 ×0.4 阶梯。

## 约定

`+L → +(L+1)`：

- **目标级及以上**玄晶（等级 ≥ L+1）：单颗 **100%**
- **当前级及以下**：从 100 起，每低一级（含当前级那一步）做一次 `floor(/3)`
- 多颗累加，封顶 100%

## 样例

| 强化 | 材料 | rate |
| --- | --- | ---: |
| +4→+5 | 1×五级 | **100%** |
| +4→+5 | 1×四级 | **33%** |
| +4→+5 | 1×三级 | **11%** |
| +4→+5 | 1×二级 | **3%** |
| +0→+1 | 1×一级 | **100%** |
| +15→+16 | 1×十六级 | **100%** |
| +15→+16 | 1×十五级 | **33%** |
| +15→+16 | 3×十五级 | **99%**（33×3） |
| +15→+16 | 4×十五级 | **100%**（封顶） |

## 公式

```text
unit(tier) = 100                         // tier > L
unit(tier) = floor(100 / 3^steps)        // tier <= L, steps = L - tier + 1
rate = min(100, Σ unit(tier_i) * count_i)
```

`29/1` 本地显示已按当前等级编码为 `required=100`、`power=unit_rate`
（见 `2026-08-01-enhance-client-display-unit-rate.md`）。真实预览/掷骰仍以
`29/2` `value` / `29/3` 为准。
