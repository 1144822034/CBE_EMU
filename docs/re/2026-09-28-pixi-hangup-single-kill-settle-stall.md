# 挂机单体技能击杀后空等再结算

日期：2026-09-28

## 症状

挂机使用单体技能打死最后一只怪后，场上会停顿一会儿（灰尸 / 空场），然后结算面板才突然弹出。

## 根因

1. 单体技能命中拍早：`windupOnly` 约 200ms 后 eidolon 与伤害同拍，击杀判定很快落地。
2. 致死后 `playDeathMotion` 仍 **完整 await** `f_death` 水花（约 5×130ms），再叠加伤害后 lead（200ms）与灰化冻结（280ms），结算被挡约 0.6–1s。
3. 既有契约（`2026-08-30-pixi-battle-cbe-timing-continuity.md`）已要求尸体淡出不挡 `4/7`，且致死后不 await 残留 eidolon；水花仍被 await，与契约不一致。
4. 普攻路径冲刺本身较长，停顿不显眼；挂机单体技能首击即终局时最明显。

## 修改（`BattleScreen.ts`）

1. 敌方死亡：灰化后 **fire-and-forget** 水花与淡出，不再 await 整段 splash。
2. 本包脚本无后续可播 action **且场上无存活敌**（wipeKill）：缩短伤害→死亡 lead / 灰化 hold。
3. 致死 child 仍先播 **受击闪**，再进死亡（群攻次要目标不再跳过受击直接灰化/结算）。
4. 结算前若仍有 HP≤0 但未播死亡的尸体，补受击+短死亡，避免多怪场直接弹结算。
5. 非致死仍 await eidolon；致死路径继续不 await 残留 eidolon。

## 验证

1. 挂机单体技能一击打死：灰化/水花可见，结算应紧随其后，无明显空场卡顿。
2. 多怪 / 群攻致死：每只被打中的怪先受击再死亡，不应「其它怪站桩就结算」。
3. 多怪打掉一只（未全灭）：应继续反击/下一手，不得因短死亡误判终局。
4. 玩家死亡 pose 路径不变（仍播完 death.gif）。
5. 群攻终局、普攻终局观感不回退。
