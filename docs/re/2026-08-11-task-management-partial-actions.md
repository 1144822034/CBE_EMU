# 任务管理：保存与恢复默认的局部提交

## 原有行为

任务管理的“保存任务”及内置任务的“恢复 task.dsh 默认”均通过普通表单提交并接收
服务端 `303` 跳转。浏览器因此重新加载整页，丢失任务目录的滚动位置。

## 修正

- 为 `save-task` 与 `delete-task-override` 表单标记局部提交契约。
- 提交仍使用原来的 `/action`、请求字段、服务端处理器和重定向目标；前端只消费其
  返回的同一份任务页 HTML。
- 成功后替换任务目录和编辑区，恢复 `data-admin-list` 的滚动位置，并同步浏览器 URL。
  因此保存、新建、恢复内置任务默认定义、删除自定义任务都会反映到目录计数与条目。
- 网络或响应片段失败时，只在任务编辑区显示错误；没有重试或伪造成功。未启用
  JavaScript 时保留原有整页表单跳转。

## 验证

- 管理端脚本通过 Node.js 语法检查。
- `make -j2`。
