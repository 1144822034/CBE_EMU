# 后台账号 W 币面板可见性（2026-08-24）

## 现象

打开后台“账号管理”并选中账号后，正文中的“账号 W 币：0”“W 币归账号所有，全部角色共用”和“加 W 币”表单会消失；同一段文字短暂显示在页面右侧。

## 根因

账号钱包区域使用了 `notice ok` 样式。共享后台脚本 `setupAdminToasts()` 将所有匹配
`.notice.ok,.notice.error` 的节点当作一次性操作结果，读取文本后从正文移除，再渲染为右侧五秒自动关闭的浮层。钱包区域本身包含加币表单，因此表单也被一并移除，而不是布局或钱包读取失败。

## 修复与边界

- 钱包区域标记为 `data-admin-persistent-notice` 和 `account-wallet`；它仍保持原有成功状态配色，但语义上是持久的账号资料卡。
- 提示脚本会跳过该标记，只将一次性成功/失败结果转为右侧提示。
- 钱包余额、`add-wcoin` 请求字段、写库路径和权限校验均未改变；本次只修正后台 HTML 的生命周期与布局。

## 验证

`scripts/admin-request-length-regression.c` 断言共享提示脚本包含持久节点排除规则；该测试不连接 MySQL，也不会写入账号或钱包数据。完整构建仍使用 `make -j2`。
