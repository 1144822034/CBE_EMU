# 组队战斗死亡后使用复活石崩溃

## 压缩结论

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 组队中一人死亡后用复活石，某角色闪退 | 幸存者继续战斗后仍向死亡/已退出 Battle.cbm 的队员投递共享 `4/6`；复活石 `4/8` 拆战斗模块后下一轮询再吃 `4/6` 即崩 | 队列与投递对 `absent`(HP=0/`leftMask`) 预标记已送达；复活/普通复活退出时 `leftMask`+清空未投递事件，且不把满血写回本场 `battleMemberHp` |

## 契约

- 共享 `4/6` 只给仍在战斗 UI 中的存活队员。
- 死亡提示、逃跑、复活石 `4/7→4/8` 之后，该席位退出本场战斗投递集合。
- 复活石恢复的是 durable/online HP；本场 `battleMemberHp` 保持 0 并置 `leftMask`，避免重新进入 `alive_mask` 屏障。

## 验证

两人组队，一人死亡：

1. 存活方继续出手，死亡方停留在复活提示：死亡方不应再收到 `team_battle_action_deliver`。
2. 死亡方确认复活石：自身正常出战斗回场景；存活方战斗继续，双方不闪退。
3. 日志可见 `team_battle_member_exit ... revival=1`，且死亡方无后续 `action_deliver`。
