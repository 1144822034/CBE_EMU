## 2026-08-07 修正

- **酷宝列表**：服务端 `14/5` 只下发非装备上架商品（`shopDbListed` 或原生类别 14），价格用表内 `price`；Pixi 按页拉全 `14/5`。
- **背包只见玄晶**：根因是解析优先了残缺的 `30/21`/`7/7` 且一行失败就截断。改为优先完整 `17/1`，逐行容错；`7/7 type=1` 只做按 seq 合并。
- **背包/商城看不全**：LCD 一屏约 10 行。UI 加分类 Tab（背包：装备/药品/…；商城：全部/药品/秘宝/其他，无装备 Tab）+ 分页；←→ 换分类，↑↓ 在当前分类内滚动（自动换页）。
- **人物信息汇总**：Pixi 专用 `1/1/21`，服务端用 `vm_net_mock_role_build_player_stats` 下发基础+装备全额（含物攻/闪躲/暴击/护甲）；客户端不读裸 actorinfo、不本地加装备。CBE 仍走 actorinfo + wear-apply。
- **背包 UI**：对齐 CBE「背包」壳——胶囊标题、六分类、黄字 `%d/%d个`、品质色列表、**金/银/铜栏用 `jin.gif`/`yin.gif`/`tong.gif` + `font_gb.uc3` 白字**、确定/返回。
- **装备详情**：CBE 同屏详情——品质色标题、`[等级]/[耐久]`、主属性黄值、`强化附加` 亮/灰四档、底栏装备/强化；←→ 翻页。
- **道具详情**：CBE 同屏——标题名、暗色说明区（`item.dsh` 说明）、底栏使用/丢弃/返回；`usable` 对齐 mock：`类别=10` 或 HP/MP/EXP/是否消耗。
- **物品使用反馈**：`useItem` 等服务端响应；解析 `7/1 result` / `16/2 hint`；黄金/白银/青铜宝箱走 `1/7/15`（自动找匹配钥匙），成功提示「获得N个…」，失败提示钥匙/空间等；面板中央 tip + 聊天栏 + 状态条。
- **经验卡反馈**：官方 809/810/811 走 `1/7/30`，解析 `result`+`iteminfo`（如「获得2倍经验值…」或「同类效果已生效…」）；自定义 845 仍走 `7/1`，成功时用同套文案、失败吃 `16/2 hint`。
- **战斗心得 828**：走 `1/25/6` + follow-up `1/25/7`（勿用通用 `7/1`，否则无响应）；tip 用服务端 `iteminfo`，面板 tip 绿色字。
- **宝箱「不存在」**：根因是 Pixi 用 `17/1` 假行号当 seq 发 `7/15`。改为 `1/7/23` 附带 `30/21` 真实 seq，打开背包后开箱即可。
- **属性页 UI**：对齐 CBE「属性」壳——顶栏胶囊「属性」、黄名、**标签左/数值右两列**、暗行底、云纹边角、▲▼ 翻页、右下「返回」；数据仍走 `1/1/21`（含配偶/帮派/expNext）。
- **列表每次打开即时拉**：背包 `7/42`、装备 `1/7/22`、商城 `1/14`+`14/5`、技能 `12/1`、人物 `1/1/21`；打开时先清空本地缓存再请求。
- **商城余额**：用 **`1/14/4`**（coolmoney=wcoin），勿用无 actorId 的 `1/1/14`。
- **上架秘宝 800 不显示**：曾因装备占满前页；现商城**停售装备**（`14/5` 仅非装备，`14/6..13` 空，`14/3` 拒售装备），800 等秘宝可正常出现。
- **装备信息 UI**：对齐 CBE「装备」壳——胶囊标题、中心角色、左帽衣披束/右裤鞋饰品武器、黄框光标、下方详情（无类型/职业）；确定弹「替换/卸载」；替换列出背包同部位装备并 `7/9`（空槽 `7/8 type3`）；卸载 `7/8 type4`。
