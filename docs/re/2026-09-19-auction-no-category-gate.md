# 拍卖行按类别拦截开关

## 触发

拍卖行上架曾复用玩家交易校验，关闭「按类别拦截」后仍拒绝绑定、任务关联、已强化、宝石/碎片等。

## 配置

后台「拍卖行」基础配置「按类别拦截」（`server_auction_config.category_gate`，默认 0）。

| 开关 | 上架 |
|------|------|
| 关 | 绑定、任务、玄晶、已强化、散装宝石/碎片可上架 |
| 开 | 与玩家交易相同：上述物品拒绝，`message=not-tradeable` |

**已镶嵌装备**：无论开关，均需先拆除宝石；上架返回 `message=socketed`（客户端提示「请先拆除宝石」）。不把孔位带进拍品。

玩家面对面交易与帮派仍用 `vm_net_mock_item_is_tradeable`，不受此开关影响。

## 验证

1. 拦截关 → 绑定/任务、已强化、散装宝石/碎片可上架
2. 已镶嵌装备上架 → `socketed` / 「请先拆除宝石」；拆完后可上架
3. 拦截开 → 散装宝石等 `not-tradeable`
4. 玩家面对面交易仍不能放入玄晶、绑定、已强化、宝石、已镶嵌装备
