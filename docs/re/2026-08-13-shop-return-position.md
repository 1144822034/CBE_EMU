# 商城返回场景位置

## 现象

从商城回到场景时，角色先按数据库中的原位置重入，随后又被重置到场景默认出生点。

## 协议链路

商城返回会先收到带坐标的 `30/2` 场景结果，客户端随后按固定流程发送
`25/5 + 2/3 + 27/11 + 7/42` 的场景进入完成组合包。该组合包内的 `2/3`
坐标是 SCE 默认落点，不表示一次新的传送。

## 根因与修复

服务端在下发 `30/2` 后立即清除了商城返回标记，后续组合包便被当作普通传送，
并将默认落点写回角色位置。现在会在会话中短暂保存商城返回的精确场景与坐标，
仅在紧接着的同场景完成组合包中恢复该坐标；响应成功后或目标场景不一致时立即清理。
