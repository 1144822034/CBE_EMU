# 商城买壶最大数量显示为 1

## 触发与现象

商城秘宝打开神仙壶/逍遥壶详情：`⇦ 数量 1/1 ⇨`，←→ 无法加到更大；系统宋体/点阵均如此。

## 业务链路

1. 商城 `14/5` iteminfo：`price` + `stock`（服务端写 `item->stock`）。
2. `item.dsh` 加载时 col10「堆叠数」误写入 catalog `stock`（802/803 = **1**，可见堆叠契约）。
3. Pixi `maxBuyQty`：`min(99, byStock, byMoney, byFlask)`，`byStock=1` → 上限恒为 1。
4. 先前已按储量夹 `maxFlaskBuyUnitsFromBag`，但仍被 `byStock` 盖住。

## 根因

把 DSH **堆叠数** 当商城 **库存** 做购买上限；壶堆叠数固定 1，与「按份加超级储量」可购上限无关。

## 修改

`SystemPanel.maxBuyQty`：壶类忽略 `g.stock`，只按余额 / 储量剩余份数 / 99。详情文案不再对壶显示「库存 1」。

## 验证

- [ ] 空包或低储量、酷宝充足：壶详情最大数 > 1（如 `1/99` 或按余额）。
- [ ] 储量接近 500 万：最大数按剩余份数夹住；已满显示「储量已满，无法购买」。
- [ ] 普通秘宝仍可用 stock 夹上限。
