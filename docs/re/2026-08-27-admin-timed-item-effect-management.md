# 后台角色时效道具管理

## 数据来源与范围

角色操作窗口新增“时效道具”页。它只读取
`account_role_item_effects` 中属于当前账号和角色、且 `expires_unix` 尚未到期、并能通过既有
时效道具契约校验的记录。页面覆盖经验卡／修炼丹、战斗心得、大力丸／神力丸，以及活动攻击、
防御和攻防加成；每项显示物品、加成值和剩余时长。

该表是时效效果的权威存储，未把效果镜像到后台进程、客户端内存或角色二进制快照。游戏中的
经验和战斗计算本来就会按角色查询该表，因此移除成功后下一次相关计算自然不再使用对应加成。

## 移除契约

移除表单携带渲染时的效果种类、物品、加成值和到期时间。服务端在事务中用这些字段精确
`SELECT ... FOR UPDATE` 后再删除，且要求记录仍未到期。这样管理员打开页面后，若玩家已续期、
替换或自然到期，旧表单不会误删新的效果，而会提示刷新。

成功操作写入后台操作日志，记录账号、角色、物品、效果类型、加成和原到期时间；日志失败时会
明确告知效果已经移除。

## 弹窗连续操作

后台的异步提交会在内容刷新后恢复原角色操作弹窗及当前标签页。因而背包管理删除物品、时效
道具移除效果等提交完成后，窗口继续保持打开，不需要重新点“操作”进入。

## 回归

`scripts/admin-role-timed-item-effect-regression.c` 不连接 MySQL，覆盖时效道具页的渲染标记、
精确移除字段、操作日志动作标签，以及角色操作弹窗的刷新恢复脚本标记。
