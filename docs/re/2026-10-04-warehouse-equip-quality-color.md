# 仓库装备品质色：蓝装显示成绿字

日期：2026-10-04

## 现象

仓库存入/取回列表里，蓝色装备名称画成绿色。取出到背包后颜色正常。

## 根因

背包列表按 `itemId` 查 `equip.dsh` 品质。仓库取回列表原先按**显示名** `lookupItemByNameSync` 上色。同名装备有多档品质（绿/蓝/紫），Map 先命中的通常是低 ID 绿装，蓝装就被画成绿字。未命中时 DialogPanel 默认薄荷绿，看起来也像绿字。

## 修改

- 服务端取回/存入选项 description 带 `#itemId`（前缀仍为「个人仓库」/「背包」）。
- Pixi 取回列表优先用该 id 查目录品质；同名多品质且无 id 时不再猜第一件。
- 存入列表与背包一致：`lookupItemSync(itemId).quality`。

## 验证

- 同名绿装、蓝装各存一件：取回列表绿字/青字应对应品质；取出背包后与仓库一致。
- `make -j2` 已编服务端。

## 仍未知

CBE 原端是否展示 option description；多出来的 `#itemId` 若出现在原端副标题，仅为提示串。
