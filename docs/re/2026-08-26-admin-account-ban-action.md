# 后台账号管理：断开并封号（2026-08-26）

状态：已实现。

## 契约

“账号管理”中选定账号的详情页新增“账号操作 → 断开并封号”。提交必须经过已认证的后台
`/action` 路由，目标账号来自表单并由账号访问层再次确认存在。

封禁先写入权威 `account_access_bans`，写入失败时不触碰在线会话；写入成功后才对该账号的
已绑定游戏会话执行既有标准离线转换并清除绑定，随后注销用户中心会话。游戏和用户中心下一次
认证都会查询相同的封禁表并拒绝该账号。服务端短连接模型没有可由后台关闭的长连接 socket，
所以不会伪造客户端踢线包。

风险角色页的快速战斗封号和账号管理封号现在复用同一账号访问层；两者分别写入明确的原因
`risk:rapid-battle-entry-within-3s` 与 `admin:account-management-ban`。每次成功的账号管理封号
追加 `ban-account` 操作日志，记录操作人、目标账号以及断开的游戏/用户中心会话数。

## 验证

`scripts/admin-request-length-regression.c` 断言新增操作日志类型及其标签。完整服务构建仍先运行
`make -j2`；若用户正在运行的服务占用输出文件，则只链接独立候选二进制，不会终止该进程。
