# Pixi 聊天频道面板

## 需求

分类显示聊天；←→ 切换频道；发送走当前频道；输入框不用 `window.prompt`。

## 契约

`docs/re/2026-07-16-chat-message-system.md`：

| 频道 | 请求 type | 下行 type |
|------|-----------|-----------|
| 世界 | 0 | 0 |
| 队伍 | 2 | 2 |
| 帮派 | 3 | 3 |
| 本地 | 4 | 4 |
| 系统 | — | 5/6 |
| 私聊 | 1/3/2 | 7 |

面板页签（与截图一致）：世界 / 派 / 本(=本地+私聊展示；无目标发本地，有私聊目标发 `1/3/2`) / 伍 / 统。

私聊入口见 `docs/re/2026-08-13-pixi-private-chat.md`。

## 修改

- `ChatPanel` + `ChatIme`：页签、颜色分行、底部输入条 + HTML IME。
- `sendChat(type)`：非世界频道本地回显（空 ACK 契约）；`type=7`/`sendTo` 走私聊。
- 菜单「聊天信息」、HUD 社交图标、快捷键 `C` 打开面板；软键发送/返回。

## 验证

1. 打开聊天 → 见分类页签；←→ 切换过滤列表。
2. 世界输入发送 → `1/3/1 type=0`，列表出现黄字 `[世]`。
3. 伍/派/本发送走对应 type；有私聊目标时本频道发 `1/3/2`；统不可发。
4. 无 `window.prompt`。
