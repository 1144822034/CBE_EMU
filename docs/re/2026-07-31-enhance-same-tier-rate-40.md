## 约定（历史）

`+15→+16` 使用 **1 颗十五级玄晶** 成功率改为 **40%**；`+14→+15` … `+1→+2` 用同级玄晶同样 **40%**。

## 公式

玄晶强度不变：

```text
power = 玄晶等级 × 100 × 数量   // 一级=100 … 十五级=1500
```

需求 / 铜币（原 `(L+1)×100`）：

```text
required(+0→+1)     = 100
required(+N→+(N+1)) = N × 250    // N = 1..16
rate = min(100, power × 100 / required)
```

同级一颗：`(N×100)×100 / (N×250) = 40`。

| 强化 | 材料 | rate |

| +14→+15 | 1×十四级 | 40% |
| +1→+2 | 1×一级 | 40% |
| +0→+1 | 1×一级 | 100% |
