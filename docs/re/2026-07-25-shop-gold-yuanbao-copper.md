# 商城金元宝（808）购买不加铜币

Date: 2026-07-25

Status: implemented

## 1. 触发与现象

- 酷币商城购买「金元宝」(itemId=808) 成功后，角色铜币不增加。
- 预期：每购 1 个增加 `1000000` 铜（HUD 显示为 100 金）。

## 2. 链路与证据

1. 请求：`1/14/3` W 币购买（`builtin-shop-buy14`）。
2. 旧服务端路径：扣 W 币后 `role_add_backpack_item(808)`，回 `14/3 {seq,result}`。
3. 客户端 `mmShopMstarWqvga.cbm:sub_9DE` 成功分支（约 `0xCEE`）：
   - `806`：本地背包容量 +4，跳过通用插入；
   - `808 = 0x65<<3`：直接跳到无插入路径（`0xDAC`），**不改本地铜币**；
   - `817..819`：同样跳过插入。
4. `item.dsh` 808：`购买个数=100`，说明含「100」；HUD 换算 `1金=10000铜` → `100*10000=1000000`。
5. 既有结论（`2026-07-24-account-21642502-login-backpack-crash.md`）：808 不是通用背包格子物品。

## 3. 根因

首次偏离在服务端购买契约：把 808 当普通入库商品，而客户端成功路径既不入库也不加铜。权威铜币应由服务端按 DSH「100 金」直兑，并通过商城可解析的 `1/1/14 actorinfo`（含 money）刷新 HUD。

## 4. 修改

- `shop-buy14` 对 808：扣 W 币、`money += 1000000*count`、不入库、`seq=0/result=1`，附带 `1/1/14 actorinfo`。
- 常量：`VM_NET_MOCK_GOLD_YUANBAO_ITEM_ID=808`，`GOLD_UNITS=100`，`COPPER_PER_GOLD=10000`。

## 5. 验证

1. 商城买 1 个金元宝：日志 `direct_gold=1 copper_grant=1000000 money=before/after`，响应 `14/3+1/1/14`。
2. HUD 铜币/金立即 +100 金；背包不出现 808。
3. 重登后 `role->money` 仍含本次增加。
4. 买 806/801 等原路径不受影响。

## 6. 仍未知

- 旧角色库里已持久化的 808 行是否应迁移为铜币：未取证兑换协议，暂不自动转换。
- 817–819 礼包开箱内容仍 `unresolved`。
