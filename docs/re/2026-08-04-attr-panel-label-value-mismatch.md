# 2026-08-04 属性面板 力/敏/智/物攻 显示错位

## 现象

天机角色、未穿戴装备，属性页显示：

| 标签 | 显示 |
| --- | ---: |
| 力量 | 80 |
| 敏捷 | 219 |
| 智慧 | 146 |
| 物攻 | 0 |

用户预期：天机应 力 > 敏 > 智；无装时仍想看到物攻。

## 运行时证据（session 802519）

`mock_actorinfo_attrs`（role=1, job=1 天机, level=70, 无装备加成）：

```text
bareStr=219 bareAgi=146 bareWis=76
word0_str=219 word1_agi=146 word3_wis=76
eqAtk=0 battleAtk=219(=jobPrimary)
```

客户端 paint 半字（`0x01022366`，actor 内存）：

```text
jobByte=0 str122=219 agi124=146 wis126=76 atk130=0 armor132=183 hit=101
```

成长表校验（job1 L70）：`12+69*3=219`、`8+69*2=146`、`7+69*1=76` — 与内存一致。

显示 `80/219/146/0` ≠ 内存 `219/146/76/0`，故问题在 **UI 填值与标签对齐**，不在 actorinfo 播种。

## 根因

属性页有两套表：

1. **标签**（`0x01022600` → `0x01019C88`）20 项顺序为：  
   称号,等级,职业,配偶,帮派,**魅力**,生命,法力,经验,(空),**力量,敏捷,智慧,物攻**,护甲,躲闪,命中,暴击,抗性,活力
2. **数值**（`InitSceneViewport` `0x010221EE` 经 `0x0101A646` 顺序 append）在战斗属性段为：  
   … → **`actor+0x84` 魅力** → `+0x122` 力 → `+0x124` 敏 → **`+0x130` 物攻** → 护甲…  
   （与 paint-8 相同，**不写 `+0x126` 智慧**）

因此标签/数值从「力量」起错位：

| 行 | 标签 | 实际写入 |
| --- | --- | --- |
| 10 | 力量 | 魅力（本例 80；当时误用等级+金钱播种，见 `2026-08-04-charm-flower-item-only.md`） |
| 11 | 敏捷 | 力量 219 |
| 12 | 智慧 | 敏捷 146 |
| 13 | 物攻 | 物攻 0（无武器） |

`atk130=0` 符合既有契约：面板物攻仅武器 `item+0xFA` 穿戴 apply（见 `2026-07-29-actorinfo-attack-word-mapping.md`）。

## 假设判定

| ID | 假设 | 结果 |
| --- | --- | --- |
| H_C | job 错成鬼道成长 | **拒绝**（job=1，bare 符合天机） |
| H_E | 装备加成抬高敏/智 | **拒绝**（eq\*=0） |
| H_A | 半字错 / 标签错位 | **确认**（半字正确，列表填值与标签不一致） |
| H_D | 无装物攻为 0 | **确认**（客户端契约，非播种遗漏） |

## 修复（host 展示层）

在 `0x01022426`（`InitSceneViewport` 尾声）按标签语义重写 **value 字符串行**（`R9+0x6390`，stride `R9+0x631E`）：`vm_host_realign_attr_panel_value_rows` in `src/main.c`。

| 行 | 标签 | 写入来源 |
| --- | --- | --- |
| 5 | 魅力 | `actor+0x84` |
| 10 | 力量 | `+0x122` |
| 11 | 敏捷 | `+0x124` |
| 12 | 智慧 | `+0x126` |
| 13 | 物攻 | `+0x130`（无武器仍为 0） |
| 14–18 | 护甲…抗性 | paint-8 半字 |

不改 actor 半字、不改 actorinfo 播种、不 patch CBE 代码。权威属性仍在半字；仅纠正 CBE 填值顺序与标签表不一致导致的展示错位。

## 验证（session 802519 post-fix）

`attr_rows_realigned`：`charm=80 str=219 agi=146 wis=76 atk=0`。

属性页 value 行（修复后）：

| 行 | value | 含义 |
| --- | ---: | --- |
| 5 | 80 | 魅力 |
| 10 | 219 | 力量 |
| 11 | 146 | 敏捷 |
| 12 | 76 | 智慧 |
| 13 | 0 | 物攻（无武器） |

对比修复前：`10=80 / 11=219 / 12=146 / 13=0`（魅力挤占力量行）。

## 仍未知 / 产品边界

- 若产品要无武器时显示战斗攻击力：需单独契约（面板 halfword vs `playerStats.attack`），不能把 battle attack 塞进 `word[4]`。
