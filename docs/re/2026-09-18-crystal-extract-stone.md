# 玄晶提炼石（装备强化玄晶回收）

## 功能

已强化装备详情增加「提炼」：

1. 消耗背包 **1× 玄晶提炼石（item 854）**
2. 将本装备强化过程中实际投入的玄晶退回背包（含失败消耗）
3. 销毁该装备（洗练快照一并清除）

## 协议

- PixiJS-only：`1/29/16 { equipseq:u16 }` → `29/16 { result, equipseq, stoneseq, remaining, spent }`
- `spent`：成功时为 `"901:2,905:1"` 文本（itemId:count）

| result | 含义 |
|--------|------|
| 1 | 成功 |
| 2 | 提炼石不足 |
| 3 | 装备不存在 |
| 4 | 未强化 / 无可提炼玄晶 |
| 5 | 背包空间不足 |
| 6 | 扣除失败 |
| 7 | 发放玄晶失败 |

## 账本

表 `account_role_enhance_crystal_spent`：`(role_id, item_instance_id)` → `spent`。

- 每次 `29/3` 强化确认（成功或失败）累加本次材料
- 首次触碰无账本的旧 +N 装备：先按「每级 1 颗对应等级玄晶」种子，再累加本次
- `29/6` 强化转移：账本从源 instance 迁到目标 instance
- 提炼成功：删除账本与洗练记录

无账本的旧强化装提炼时同样走「每级 1 颗对应等级玄晶」回退（无法还原历史失败消耗）。

## 道具

- id **854**，商城酷宝上架，耐久 1，可堆叠
- 禁止通用 `7/1`；从装备详情「提炼」走 `29/16`

## 背包空位

提炼前必须确认空位够放下「尚未拥有堆叠」的玄晶种类：

- 服务端权威：按账本（或 +N 回退）统计需新开堆叠数；销毁装备（及最后一颗提炼石）先释放格位后再比
- 不足 → `result=5`，并带回 `needslots` / `freeslots` / `spent`
- 客户端点「提炼」与发请求前各做一次同口径预检，提示「需空出N格存放玄晶」

玄晶按 itemId 堆叠，同种类已有堆不占新格。
