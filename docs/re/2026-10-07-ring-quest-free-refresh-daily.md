# 跑环每日免费刷新（2026-10-07）

## 需求

跑环使者「刷新跑环」优先使用**每日免费次数**；用尽后仍可花 10 酷宝刷新。免费次数由管理后台「节日/跑环」页配置。

## 契约

| 层 | 内容 |
|----|------|
| 配置 | `server_ring_config.free_refresh_daily`（默认 3；0=仅酷宝） |
| 当日计数 | `account_role_ring_daily.free_refresh_used`（按角色/自然日） |
| WT47/1 状态 | 增补 `freeRefreshMax`、`freeRefreshUsed` |
| WT47/5 刷新 | 有剩余免费 → 不扣酷宝，`message=ok_free`；否则扣 10 酷宝，`message=ok_wcoin` |
| 客户端确认 | 按剩余免费次数切换文案；仅 `ok_wcoin` 时本地扣 coolmoney |

不增减当日已完成环数；须先有进行中环任务。

## 验证

1. 后台把「每日免费刷新次数」设为 2 并保存。
2. 接环后点「刷新跑环」→ 确认框显示剩余免费次数 → 任务重抽、环数不变、酷宝不变。
3. 连续免费刷满配置次数后，再刷新确认框提示消耗酷宝；酷宝 −10。
4. 免费与酷宝均不可用时提示「酷宝不足」。
5. 次日（自然日）免费次数重置。
