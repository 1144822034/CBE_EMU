# 出售 / 仓库即时 role_db_save（2026-09-13）

## 背景

丢弃故意 deferred（同步 save 会卡连续丢的 7/4）。出售与仓库存取若也
deferred，服务端崩溃窗口下可能出现消耗回滚；仓库路径历史上还有背包/仓
快照分裂风险。

## 修改

`vm_net_mock_role_persist_inventory_now`：先 `role_db_save`，失败才 dirty。

| 路径 | 落库 |
| --- | --- |
| 装备出售 `equip-sell` | 即时 |
| 仓库存入（含药瓶合并） | 即时 |
| 仓库取出 | 即时（含仓槽删除 + 入包） |
| 丢弃 | 仍 deferred |
| 穿脱 | 仍 deferred |

- [ ] 存仓 / 取回后杀进程重登：背包与仓库互斥、无双份
- [ ] 连续丢弃仍不卡 7/4
