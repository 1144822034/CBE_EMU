# 法术命中与物理/法术暴击模型

Date: 2026-08-13  
Status: implemented; manual battle verification pending

## 1. 当前卡点

- 可见现象：攻击法术会显示“闪躲”，暴击伤害只有普通伤害的 1.5 倍，体感偏低。
- 本轮最小目标：攻击法术不参与闪避；将物理、法术暴击评分和伤害倍率分开，同时保留
  客户端既有的 `4/6.actioninfo` 显示协议。

## 2. 当前实现与运行链路

客户端对战斗操作发送 WT `4/2`（自动战斗由空 `4/12` 复用同一 `4/2` 意图）。服务端
的 `vm_net_mock_battle_apply_player_attack_targets` 选择每个目标后调用：

```text
普攻 -> vm_net_mock_battle_player_damage_to_enemy
法术 -> vm_net_mock_battle_player_skill_damage_to_enemy
      -> actioninfo child_flag / HP delta -> WT 4/6
```

现有 `mock_server_role.c` 显示：

- `vm_net_mock_battle_player_skill_damage_to_enemy` 在技能伤害、防御结算之后调用了
  `vm_net_mock_battle_player_attack_hits`；因此法术和普攻都可能输出零伤害与闪躲标记。
- `vm_net_mock_battle_apply_player_critical` 同时被上述两条路径调用，统一按
  `roleCrit / (1200 + roleCrit)` 取概率（上限 35%），并将最终伤害乘以 150%。

这是服务端第一次偏离用户要求的位置，不是客户端动作解析或显示问题。

## 3. IDA / 协议证据

当前动态 IDA 实例按 `binary_name` 查询到 `江湖OL.CBE`、`mmGameMstarWqvga.cbm` 等模块；
本轮客户端尚未装载 `mmBattleMstarWqvga.cbm`，因此没有把任意地址误映射到其他模块。

既有、已记录的 Battle 模块取证仍直接适用本响应对象：

| binary | function/address | finding |
| --- | --- | --- |
| `mmBattleMstarWqvga.cbm` | `HandleBattleActionMsg(0x6EB0)` | 读取服务端写入的目标槽、HP 变化和 child flag，不在客户端二次计算命中或暴击。 |
| `mmBattleMstarWqvga.cbm` | `0x2456` | child flag `3` 显示“闪躲”，flag `2` 显示“暴击”。 |

该结论已在 `2026-08-12-battle-secondary-stat-settlement.md` 中由静态/运行证据交叉
记录。它说明服务端只需保持现有 actioninfo 字段布局：法术命中时输出正常伤害或暴击，
不应发送 flag `3`；物理和法术暴击仍都使用 flag `2`。

## 4. 伤害与暴击设计边界

`skill.dsh` 提供攻击技能的基础生命变化以及力量、敏捷、智慧系数，但没有“魔法暴击”
或“暴击倍率”列；`equip.dsh` 也只有一个共享的暴击词条。原服的概率/倍率表没有位于
当前客户端或本地资源中，不能宣称已恢复原始常数。

保留已经验证的伤害顺序：

```text
原始伤害 -> 防御减伤 -> 暴击倍率 -> 目标当前 HP 钳制
```

本服务端采用明确的平衡规则：

```text
共享暴击评分 = 现有角色 crit（含装备与临时效果）
物理暴击评分 = 共享评分 + 敏捷 / 6
法术暴击评分 = 共享评分 + 智慧 * 3 / 10
暴击概率       = 评分 / (1200 + 评分)，上限 35%
物理暴击伤害   = 已减伤伤害 * 1.75
法术暴击伤害   = 已减伤伤害 * 2.00
```

因此装备/词条“暴击”同时作用于两类攻击；敏捷额外偏向物理暴击，智慧额外偏向法术
暴击。概率上限和伤害先减伤后放大均保持，避免高属性产生必暴或无上限溢出。

## 4.1 普通攻击命中下限（2026-08-13）

普通攻击仍按 `命中 / (命中 + 怪物躲闪)` 结算；怪物躲闪为
`20 + 怪物等级 * 2`。此前命中率限制在 60%～95%，会令低敏捷的同级角色长期承受
40% 的普通攻击躲闪，明显高于常规战斗的可接受范围。

现调整为 85%～95%：命中、敏捷与装备命中仍能把命中率由 85% 提高至 95%，但普通
怪物的躲闪最多为 15%。攻击法术仍固定命中，不使用这一判定。

## 5. Negative Evidence

- 当前没有独立“法术暴击”资源字段，不能凭空增加数据库或客户端展示属性。
- 当前只有角色 `resist`，没有怪物独立魔抗字段；攻击法术仍按现有怪物防御曲线结算，
  本轮不把缺失字段伪造成零魔抗。
- 法术 actioninfo 的客户端显示与普攻共用 flag `2`；不能为了区分服务端概率而改造
  客户端标志含义。

## 6. 本轮实现计划

目标文件：`src/server/mock_server_role.c`。

1. 给暴击辅助函数传入攻击类型，依据上述独立评分和倍率计算；
2. 普攻调用物理暴击分支，攻击法术调用法术暴击分支；
3. 移除攻击法术对普攻命中/闪避函数的调用，固定为命中；
4. 不改变 WT、actioninfo、目标选择、护盾/控制/治疗分支或客户端代码。
