# PixiJS 开场「江湖支招」随机文案

## 现象

开场 tip 不是固定一句；原版每次进入标题前可能打出不同正文。

## 证据

`bin/CBE/江湖OL.cbe` GBK 字符串区（约 `0x502EB` 起，约 256 字节一条）：

| # | 正文（去色标后） |
|---|------------------|
| 0 | 仗剑江湖载酒行，赤胆雄心照前程，我辈岂是池中物，一遇风云化做龙。 |
| 1 | 玫兰杜康寄友情，笑看江湖谁最风流! |
| 2 | 一段故事一个江湖，一场姻缘一段佳话。 |
| 3 | 蜀山有情聚一帮，一帮兄弟一个家! |
| 4 | 桃缘再劫，临安月老渡你心愿达成。 |
| 5 | 擂台宗主广邀天下英雄共赴蜀山南，踢台夺金。 |
| 6 | 江湖儿女的友好度达到3000，即可成就一段良缘! |

色标：`c0` 米黄正文，`c2`/`c9` 青色（标题或关键字）。UI 标题固定为 `【江湖支招】`。

## 修改

- `PixiJS_web/src/ui/bootTips.ts`：嵌入上述 tip 池，解析色标，每次 `play()` 随机（避免连抽同一条）。
- `TipBootLayer`：按字打字机 + 色标着色，再进「获取版本信息」。

## 验证

刷新标题流多次，应轮换不同正文；软键跳过仍进 logo/菜单。
