# 强化基础属性统一倍率 + 查看属性 (+值)

## 缩放契约（穿戴汇总）

对 `equip.dsh` 中基值 > 0 的列（物攻/护甲/气血/法力/力量…）：

```text
M(L) = 1 + (10*L + 35*floor(L/4)) / 100
scaled = base * M(L)   // 实现为 base + base*(10L+35*floor(L/4))/100
```

| 步 | 相对基值 |
|---|---|
| 普通级 | +10% |
| +4/+8/+12/+16 | +45%（含该级 10% + 额外 35%） |
| +0 → +16 | **正好 4 倍** |

实现：`vm_net_mock_equipment_bonus_scale` / `_enhance_delta`（`mock_server_catalog.c`），
`collect_equipment_bonus` 与商店详情共用。强化附加 UI 仍为 L≥4 的
+4/+8/+12/+16 里程碑词条（见 `2026-07-29-enhance-attr-gray-and-unequip.md`）。

## 查看装备 (+值)

原生背包详情格式为 `c0[物攻]:c4+%d`。客户端强化表为空时主行 `%d` 仍是
dsh 基值。

商店/出售「查看属性」主数字为强化后合计，并附增量：

```text
攻击+175(+75)   // 合计(+强化增量)；未强化仍为 攻击+100
```

穿戴后角色/战斗属性已走同一 `M(L)` 公式计入。

## 验证

1. 穿戴同件装备：未强化 vs +16，装备贡献属性约 4 倍（再经攻击/3、护甲/5 折算）。
2. +3→+4 有明显跳变（额外 +35% 基值）。
3. 出售/商店查看已强化装备：属性行含 `(+…)`；商店未强化无括号。
4. `make server -j2`。
