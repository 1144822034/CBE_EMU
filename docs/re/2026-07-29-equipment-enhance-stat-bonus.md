# 强化装备攻击/护甲加成未计入角色属性（2026-07-29）

## 1. 现象

穿戴已强化装备后，强化等级（`(+N)`）显示正常，但角色攻击/防御等战斗属性
与未强化时几乎无差，表现为「强化加成没生效」。

## 2. 根因

权威属性汇总在 `vm_net_mock_role_collect_equipment_bonus`：

- 只按 `equippedItemIds[slot]` 查 `equip.dsh` 基值并累加；
- **从未读取** `equippedEnhanceLevels[slot]`。

强化等级已在背包/穿戴/29/3/登录路径正确持久化与回包，但未进入
`vm_net_mock_role_build_player_stats` → actorinfo / 战斗开局血攻防链路。

首次偏离点：装备加成收集层忽略强化契约，而非客户端解析或存档丢失。

## 3. 客户端证据（`江湖OL.CBE`）

| 地址 | 作用 |
| --- | --- |
| `0x01028BCE` | 强化缩放：`attr += base`，再对 `i in [0,L)` 累加 `flat_i + pct_i*base/100` |
| `0x0101002E` | 武器类调用：基值来自装备块 `+0xFA`（攻击），`L` 来自 `+0xE` |
| `0x01010056` | 防具类调用：基值来自 `+0xF8`（护甲），同样用强化等级作循环上限 |

其他 `equip.dsh` 列（生命/法力/力量等）在该本地装配路径上是**直接累加、不走强化缩放**。

每级表项 `(flat_i, pct_i)` 来自运行时表指针（`global+0x580+4`），静态二进制中未找到定长常量表；**表内容仍为 unresolved**。

## 4. 服务端缩放（2026-07-29 修订）

对所有基值 > 0 的 `equip.dsh` 列统一：

```text
M(L) = 1 + (10*L + 35*floor(L/4)) / 100
```

普通级 +10% 基值；+4/+8/+12/+16 该步 +45%；+0→+16 = **4×**。
详见 `2026-07-29-enhance-scale-4x-and-view-plus.md`。

查看属性对话框显示 `攻击+基值(+强化增量)`。

### 4.3 强化附加明细（UI 词条）

客户端装备详情在 `attr_count==0` 时整段跳过 `强化附加`（`0x01032610`）。
主行 `%d` 不吃网络字段（强化表 null）。

`vm_net_mock_seq_put_item_common_extra`：

```text
L>=4: 4 槽 unlock 4/8/12/16（部位模板）
L>=1: 再追加 M(L)-base（**仅护甲→物攻**，仅 base>0；气血/法力不再追加）
合计 attr_count ≤ 6（客户端容量）
second i16 高字节 = attr_count
```

客户端 `0x01032118`：`unlock > 当前强化` 画灰色，否则亮色。里程碑必须
整组下发（详见 `2026-07-29-enhance-attr-gray-and-unequip.md`）。

- 部位里程碑模板（无标记=玩家确认；`[P]`=临时）：

| 部位 | +4 | +8 | +12 | +16 |
| --- | --- | --- | --- | --- |
| 武器 | 暴击(值) | 躲闪(值) `[P]` | 护甲(值) `[P]`（抗性向） | 命中(值) `[P]` |
| 帽子 | 护甲(值) `[P]` | 气血(值) `[P]` | 法力% `[P]` | 智慧(值) `[P]` |
| 上衣 | 暴击(值) | 气血% | 法力% | 力量(值) `[P]` |
| 披风 | 暴击(值) | 命中(值) | 躲闪(值) `[P]` | 敏捷(值) `[P]` |
| 束腰 | 护甲(值) `[P]` | 法力(值) `[P]` | 气血% `[P]` | 力量(值) `[P]` |
| 裤子 | 物攻(值) | 护甲(值) | 命中(值) `[P]` | 气血(值) `[P]` |
| 鞋子 | 躲闪(值) `[P]` | 气血(值) `[P]` | 命中(值) `[P]` | 敏捷(值) `[P]` |
| 饰品 | 物攻(值) | 气血(值) | 护甲(值) `[P]` | 智慧(值) `[P]` |

- 数值按 `equip.dsh` 品质（见 `2026-07-29-enhance-attr-quality-milestones.md`）：
  暴击/闪躲/命中=`Q+1`；气血%/法力%`(Q+1)*5`；力/敏/智`(Q+1)*120`（固定在 +16）；
  气血/法力值与物攻/护甲用品质 1..4 定表（白装品质 0 回退档 1）。
- 追加的护甲/物攻/气血/法力行为 `M(L)-base`（与穿戴汇总同一公式）；
  `L>=4` 时因容量 6，同件若四列基值都 >0，只会显示前两列（护甲、物攻）。

### 4.4 客户端补表取证（2026-07-29）

以已确认锚点（上衣 `8,9,10`、裤子 `4,5`、披风 `8,7`、饰品 `4,9`、武器 `8`）
在 `江湖OL.CBE` / 本地 `*.dsh` 中检索：

| 尝试 | 结果 |
| --- | --- |
| 连续 type 字节 `08 09 0A` | **整文件不存在** |
| `(type,flag)` / unlock+type / u16 打包 / 高位% 标记 | 无命中 |
| 8 slot×4 或 10 category×4 定长表（含 0 填充） | 无命中 |
| 含 8/9/10 立即数且 cmp 部位 的代码窗 | 无命中 |
| `equip.dsh` / `item.dsh` / 玄晶说明 | 无部位词条池 |

结论：缺失档位/部位的词条**不在客户端静态表**；客户端只解析网络
`ParseEquipAttributes` 槽位并展示。补全仍依赖实机明细或官服抓包。
