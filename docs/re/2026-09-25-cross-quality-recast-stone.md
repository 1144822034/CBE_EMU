# 跨品重铸石（强化转移跨品质）

## 功能

背包持有 **跨品重铸石（item 855）** 时，强化转移（重铸）可选 **同部位、不同品质** 的目标装备：

1. 仍要求源强化等级 ≥ 1；客户端目标列表只列 **未强化（+0）** 同部位装备
2. **同品质** 转移：不消耗石头，仍扣 48金65银
3. **跨品质** 确认（`29/6`）：额外消耗 1× 跨品重铸石，并扣金钱
4. 预览（`29/5`）只校验石头是否在背包，不扣

无石头时跨品质仍返回 `result=5`（不可转移）。
已强化目标不进入选装列表（避免误覆盖另一件已强化装备）。

## 协议

沿用既有 `1/29/5` / `1/29/6 { seqd, seqs }`，不新增 subtype。服务端在品质不等时自动查找并扣除 855。

## 道具

- id **855**，商城酷宝上架，耐久 1，可堆叠
- 禁止通用 `7/1`；在「重铸」选目标流程中间接消耗

## 客户端

`EnhancePanel`：背包有 855 时放宽品质过滤；跨品质目标带品质标签；确认页提示将消耗石头。
