# 装备出售凭证「出售背包全部装备」失效

## 触发

使用装备出售凭证(839)打开出售对话框 → 点「出售背包全部装备」→ 确认后无批量出售，或直接退出/走错逻辑。

## 根因

Pixi 客户端对话框 `action` 冲突：

| action | 先写用途 | 后写用途 |
|--------|----------|----------|
| 290 / 291 | 梦境徽章合成确认/取消 | 批量出售确认入口/确认出售 |

`dialog.onPick` 里梦境徽章分支在前且无条件 `return`，批量出售的 290/291/292 永远到不了。

首次偏离：点「出售背包全部装备」进入合成路径（`pendingDreamBadge` 为空则 `returnFromDreamBadgeCombine`），不是 `sellAllUnenhancedBagEquips`。

## 修复

- 批量出售改用独立 action：`293` 打开确认、`294` 确认出售、`295` 取消（`EquipSellBatchAction`）。
- 梦境徽章 290/291 仅在 `dreamBadgeCombineOpen` 时处理。

## 验证

1. 商城买/使用 839 → 出售对话框出现「出售背包全部装备」
2. 点选项 → 出现确认框 → 确认后 tip「已出售 N 件未强化装备」
3. 背包未强化装备减少、铜币增加；强化装仍在
4. 梦境徽章 ≥300「合成」仍可选装备并成功
