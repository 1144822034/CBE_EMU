# 2026-07-25 NPC 武器/防具商店：仅白装 + 等级段

## 触发与契约

`npc_kind=1`（武器商人）与 `npc_kind=4`（防具商人）通过 `26/1` 服务子菜单
出售装备。此前目录按 `equip.dsh` 类别分页列出全部品质，彩色装与白装混排，
高等级条目淹没低等级列表。

## 根因

权威目录是本地 `equip.dsh`：

- 列 3 `等级`：需求等级
- 列 6 `品质`：`0` 为白装，`1..4` 为更高品质

服务端装备目录原先未解析品质，NPC 商店匹配只按类别过滤，因此非白装也会进入
可购列表。

## 修改

1. `equipment catalog` 增加 `quality`，从 `equip.dsh` 第 6 列装载。
2. 武器/防具商人只出售：
   - `品质 == 0`
   - 需求等级落在 `1..70`
3. 选完装备子类后，先显示四个等级段菜单，再分页列商品：
   - `1-20级` / `21-40级` / `41-60级` / `61-70级`
4. `OPEN_CATEGORY` 低 24 位编码调整为：
   - `[7:0]` selector
   - `[11:8]` level band（`0`=等级段菜单，`1..4`=上述四段）
   - `[23:12]` page

药品商人（`npc_kind=5`）不受影响。

## 验证

- `make -j2`
- 进武器/防具 NPC：子类 → 等级段 → 仅白装条目；购买非白装 ID 应返回下架。
