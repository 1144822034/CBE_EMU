# 地图死亡态进出商城崩溃

## 压缩结论

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 提示复活石不能直接使用，进商城再退出即崩 | 地图侧 HP=0 时背包拒绝类别 14 的 `801`，且已无 Battle.cbm 故发不出 `1/7/14`；商城返回重建 mmGame 时客户端仍为 0 血 | 地图死亡买 `801`：`14/3+1/1/14 actorinfo` 当场满血；shop-return 仅作补消费并用下一拍 `1/1/1` 同步。详见 `2026-07-25-nonbattle-shop-buy-exit-crash.md` |

## 契约

- 战斗内确认仍是 `1/7/14(result=1)` → `4/7+4/8+4/11+4/9`。
- 地图死亡（Battle.cbm 已卸）时，`mmShop → mmGame` 的资源 followup 是权威消费 `801` 的替代点；购买 `14/3` 本身仍不改 HP。
- 商城返回重建场景前，角色 HP 必须非 0；否则改走普通复活落点，不得用 HP=0 的 `30/2` 关壳。

## 验证

重启服务。若账号仍为 HP=0，需背包有 `801` 后进出一次商城，或接受无石时的普通复活惩罚。

1. 地图 HP=0 + 有 `801`：进商城再退出 → 满血回原场景，不闪退；日志 `mock_shop_return_map_revival`。
2. 地图 HP=0 + 无 `801`：进商城再退出 → `20/1+30/1` 普通复活，不闪退。
3. 战斗内有石确认路径不受影响。
