# 跑环进度接入任务追踪面板（2026-08-31）

## 需求

地图左侧任务追踪在已有主线/支线已接任务之外，展示当日进行中的跑环任务与进度。

## 实现

- `QuestTrackerOverlay.buildQuestTrackerRows(..., { ring })`：`taskActive` 时把跑环插到首行（占用 `MAX_TASKS` 之一）。
- 进度文案：击杀 `n/m场`（满则「可提交」）、拜访「未对话/可提交」、收集/交药等短标签。
- `main.ts` 缓存 `cachedRingStatus`，`syncRingQuestTracker` 拉 WT47 后刷新；触发点：进图、出战回世界、跑环面板接/交/领、有活跃环时关 NPC 对话。

## 验证

1. 接一条击杀环 → 追踪首行出现「跑环·…」与 `0/N场`。
2. 打一场匹配怪出战 → 进度 +1（若服务端已计）。
3. 拜访环对话目标 NPC 关对话后 → 「可提交」。
4. 提交或无活跃环 → 跑环行消失，其余任务行仍正常。
