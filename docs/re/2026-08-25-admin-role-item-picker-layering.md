# 后台角色物品选择弹窗层级（2026-08-25）

## 触发与首个偏离

在“账号管理”中打开角色“操作”，进入“物品与装备”，点击“选择物品”。

角色操作弹窗的 `z-index` 为 1100，而共享物品选择器作为同页固定定位
弹窗只有 1000。物品选择器虽已解除 `hidden`，仍被角色操作弹窗覆盖，管理员
无法正常搜索或选择物品、装备。

## 修复

- 明确角色操作弹窗层级为 1100、物品选择器为 1200，使内层选择器覆盖外层角色
  操作弹窗。
- 关闭或选中内层选择器时，若角色操作弹窗仍打开，保留页面的弹窗滚动锁定。
- 按 Escape 时优先关闭物品选择器，不再同时关闭仍在其后的角色操作弹窗。

这只调整后台页面交互状态；授予物品的表单字段、服务端校验和角色数据写入流程
均未改变。

## 回归边界

`scripts/admin-role-item-picker-layering-regression.c` 独立断言角色“给予物品”字段仍
绑定到正确的共享选择器、内层选择器层级严格高于角色操作弹窗，并检查嵌套弹窗的关闭
状态逻辑；它不依赖称号资源或数据库夹具。
