# 菜单「玩家信息→装备」能否下发强化后主属性（2026-07-29）

## 用户所指

不是背包详情，而是：**菜单 → 玩家信息 → 装备**（本机穿戴栏）。

## 结论

| 内容 | 能否服务端下发 |
| --- | --- |
| 穿戴列表、强化等级 `(+N)` | 能，且已在 `7/7 type=2` |
| `强化附加` | 能，common-extra（L≥4） |
| 点开单件后的主行物攻/护甲 `%d` | **不能**（与背包详情同一本地绘制） |

打开该页**不会**再向服务端要一份「算好的主属性」；没有对应 WT。

## 证据

1. 子菜单表 `0x010221C6`：`称号/背包/任务/法术/装备/属性`；UI 构建
   `0x01021FD8` → `0x01019D22`。
2. 穿戴栏数据来自登录/换装播种的 `7/7 type=2`（category 15），见
   `2026-07-21-equipment-login-restore.md`。
3. 玩家信息 UI 区（约 `0x1020000–0x1028000`）**无** `bl` 到
   `SendEquipView(0x0101A2B6)`（`29/4` 仅看他人）。
4. 主行格式仍是 `c0[物攻]:…%d`（`0x010289AA`）；缩放依赖
   `business+0x584` 表，本构建无写入点
   （`2026-07-29-enhance-scale-table-no-writer.md`）。

## 合法替代

- 角色总属性：同级「属性」页 / `actorinfo`（已含 `M(L)`）。
- 单件强化增量展示：继续用 `强化附加` 词条，不要指望改主行 `%d`。
