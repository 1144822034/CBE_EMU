# 怪物四项属性的回合经济平衡（2026-08-14）

## 数据来源与比较口径

本次没有猜测客户端怪物公式。角色数据全部来自服务端当前的权威路径：

1. 无装备职业属性由 `vm_net_mock_role_build_base_player_stats()` 计算；
2. 同级品质 0 套装逐槽从真实 `JHOnlineData/equip.dsh` 选择：需求等级不高于角色等级、
   武器职业匹配、同级候选按物攻／护甲择优；
3. 怪物 HP、MP、攻击、防御由 `vm_net_mock_monster_base_stats_for_entry()` 下发；
4. 对攻回合使用战斗的同一软防御公式
   `damage = attack * 100 / (100 + defense)`，并向最近整数取整。

`automonster.dsh` 只有场景和怪物 ID 映射，不包含四项战斗属性；`server_monsters`
则是管理员的显式覆盖，不能当作未经解释的默认曲线来源。

## 实测样本

下表的无装备行取术士（职业 3，四项中最保守的常见基线）；品质 0 基准则是三职业中
每一项的最低值，用于使普通怪不会只对高输出职业成立。

| 等级 | 无装备 HP/MP/攻/防 | 品质 0 基准 HP/MP/攻/防 |
| ---: | --- | --- |
| 1 | 120 / 100 / 11 / 8 | 120 / 100 / 26 / 8 |
| 20 | 405 / 575 / 78 / 46 | 628 / 649 / 129 / 558 |
| 40 | 705 / 1075 / 148 / 86 | 1485 / 1372 / 286 / 1582 |
| 60 | 1005 / 1575 / 218 / 126 | 2234 / 1555 / 425 / 3588 |
| 70 | 1155 / 1825 / 253 / 146 | 3496 / 2253 / 791 / 5026 |

品质 0 装备的防御在中后期直接且完整地进入战斗属性，因此它是“同等级已正常装备角色”
的正确难度基线；裸装角色在高等级不应与完整套装处于同一战力层次。

旧普通怪 HP 按 `品质0攻击 × 5` 生成。装备攻击成长后，70 级最低职业要 **17** 次
普攻才能打败同级普通野兽；旧首领则需 **162** 次。首个偏离是把原始攻击直接当作生命池
倍率，忽略了战斗里防御对实际伤害的折减。

## 新曲线（V2）

普通怪先以同级品质 0 保守基准计算：

```text
普通防御 = 品质0攻击 × 20%
普通HP   = SoftDamage(品质0攻击, 普通防御) × 6
普通攻击 = ceil(品质0HP × (100 + 品质0防御) / 1400)
普通MP   = max(8 + 等级 × 3, 品质0MP × 20%)
```

普通野兽因此在最低品质 0 输出职业面前稳定为约 **6 次普攻击杀 / 14 次成功反击倒下**；
现有怪物种类倍率仍然最后应用，保留岩石、亡灵偏耐久，史莱姆、昆虫偏脆弱的差异。

首领为单体高强度战斗：

```text
首领防御 = 品质0攻击 × 50%
首领HP   = SoftDamage(品质0攻击, 首领防御) × 30
首领攻击 = ceil(品质0HP × (100 + 品质0防御) / 700)
首领MP   = max(24 + 等级 × 6, 品质0MP × 50%)
```

这使最低品质 0 角色约需 **30 次普攻**，但约 **8 次成功反击**便会倒下：单人常规对攻不应
完成，三人合力仍约需要 9～12 个协同回合，不额外引入“必须组队”的请求限制。

| ---: | --- | --- |
| 1 | 144 / 20 / 10 / 6 | 690 / 50 / 19 / 13 |
| 60 | 1374 / 311 / 5885 / 85 | 4080 / 778 / 11770 / 213 |
| 70 | 1830 / 451 / 12801 / 159 | 4770 / 1127 / 25601 / 396 |

## 覆盖数据迁移

`server_monsters` 不是默认数据缓存，后台编辑过的怪物绝不能在曲线升级时被整体重置。
启动时的一次性 `monster-quality-zero-balance-v2` 迁移在一个 MySQL 事务中：

- 仅当某行的 **HP、MP、攻击、防御** 精确等于该等级、该类型的 V1 公式结果时，才把这四项
  更新为 V2；经验、铜钱、掉落均不改动；
- 任一四项不同即视为管理员手调，完整保留；
- 迁移标记和全部更新同一事务提交，失败则回滚，下次启动重试。

因此新安装直接采用 V2；历史默认重置过的行会升级；真实运营配置不会被静默覆盖。

## 回归

`scripts/monster-balance-profile.c` 不启动服务、不连接 MySQL、不改动角色或数据库。它读取真实
`equip.dsh`，输出 1～70 级三职业的裸装／品质 0 对比及普通怪、首领回合数，并锁定 1、60、70
级的四项数值，以及 60、70 级最低品质 0 职业的 `普通=6/14`、`首领=30/8` 回合契约。
