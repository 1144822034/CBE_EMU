# 战斗结算铜币变少 / 出售装备误报

## 现象

玩家反馈丢弃/出售装备后铜币变少。服务端丢弃路径本身是 `role->money += floor(价值/10)`，
不会扣钱。

## 根因

2026-07-26 为修正结算「获得经验」显示，曾把 `4/7.exp/gold` 改成本场增益。

`HandleBattleSettleMsg` 会把响应里的 `gold` **写回 actor 当前金钱**。开战基线常为 0
时，把本场铜币（例如 9）当成新总量写入后，角色显示金钱从数百骤降到个位数。
玩家随后在背包丢装备，容易把「钱变少」归咎于出售/丢弃。

丢弃补偿 `7/4 + 10/26{money=权威余额}` 仍是加钱；被破坏的是战后 HUD 上的 actor 金钱。

## 修复

1. `4/7.exp/gold` 恢复为战后**绝对总量**。
2. 胜利结算在 `4/7` 前先发 `1/1/14` actorinfo，写入**战前**绝对经验/金钱作基线，
   使面板 `获得 = new - old` 为本场值。
3. 仍 `arm_map_actor_vitals_sync`，回场景后再推一次绝对状态。
