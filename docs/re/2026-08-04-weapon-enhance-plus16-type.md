# 2026-08-04 武器 +16 强化类型（剑/刃/杖）

## 现象

武器强化到 +16 时，详情属性类型不对：

| 武器 | `equip.dsh` 类别 | 期望 | 曾见错误详情 |
| --- | ---: | --- | --- |
| 剑 | 7 | 力量 | 显示「敏捷」 |
| 刃/匕 | 8 | 敏捷 | 显示「智慧」 |
| 杖 | 9 | 智慧 | 正确 |

## 根因

`vm_net_mock_weapon_enhance_primary_type` 的语义映射本来就是对的：
`7→力 / 8→敏 / 9→智`（与 `equip.dsh` 宽剑/匕首/杖一致）。

出错在 `vm_net_mock_equip_enhance_wire_type`：为迁就 wear-apply jump
（`1→魅 / 2→力 / 3→敏`）把语义 type 力→wire 2、敏→wire 3。  
详情名表仍按 wire 取名，于是：

- 剑 +16 语义力(1) → wire 2 → 详情「敏捷」
- 刃 +16 语义敏(2) → wire 3 → 详情「智慧」
- 杖 +16 语义智(3) → wire 3 → 详情「智慧」（碰巧正确）

服务端 `collect` 仍按语义 type 入账，所以战斗侧三围可以是对的，只有详情名偏。

## 修复

- 取消力/敏 wire remap，详情发名表 type（1/2/3）。
- 面板半字在穿脱后由 live `1/1/14` actorinfo 覆盖（见
  `2026-08-04-equip-primary-attr-refresh.md`），不再靠 jump 对齐力/敏名。

## 验证

1. +16 品质≥1 剑：详情 `(+16)力量+品质*422`  
2. +16 刃/匕：`(+16)敏捷+…`  
3. +16 杖：`(+16)智慧+…`  
4. `make -j2`
