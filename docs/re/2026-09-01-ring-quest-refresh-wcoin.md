# 跑环使者：酷宝刷新环任务（2026-09-01）

## 需求

跑环使者 NPC 对话增加「刷新跑环」：重抽当前进行中的环任务，需玩家确认；不增减当日已完成环数。

> 2026-10-07 起优先消耗后台配置的每日免费次数，用尽后再扣 10 酷宝。见 `2026-10-07-ring-quest-free-refresh-daily.md`。

## 契约

| 层 | 内容 |
|----|------|
| NPC 选项 | `VM_NET_MOCK_NPC_SERVICE_RING_REFRESH` = `0xf7000005`，文案「刷新跑环」 |
| 客户端确认 | 拦截该 value → 本地确认框「确认消耗10酷宝…」→ action `284` |
| 协议 | WT47 subtype **5**：成功 `result=1 message=ok`；失败 `noactive` / `nowcoin` / `savefail` 等 |
| 扣费 | `role.wcoin`（UI 酷宝）；失败回滚 wcoin 与环运行时 |

无进行中环任务时拒绝（须先接环再刷）。

## 验证

1. 与跑环使对话：可见「跑环任务」「刷新跑环」。
2. 无活跃环点刷新 → 确认后提示「没有进行中的环任务」，酷宝不变。
3. 有活跃环、酷宝≥10 → 确认后任务描述变化、环数不变、酷宝 −10，并打开跑环面板。
4. 酷宝不足 →「酷宝不足」。
5. 取消确认 → 不扣费、任务不变。
