# 单体治疗的单人自疗结算

Date: 2026-08-13  
Status: implemented; manual client verification pending

## 现象与首个偏离

鬼道的“清风拂体”是 `skill.dsh` 中目标指向为 `1`、生命变化为正数的单体治疗。
在单人战斗中对自己施放时，客户端播放了技能效果，但回复数值为零。

服务端将所有这类技能汇入
`vm_net_mock_battle_apply_player_friendly_single_heal_target()`。队伍战斗会根据原始
`WT 4/2.index` 找到指定友方并调用治疗公式；但单人战斗的末尾分支错误地把施法者视作
“没有合法友方目标”，固定写入 `{ target=施法者, valueA=0 }`。因此权威 HP 未更新，
且 `4/6.actioninfo` 的正向 HP 变化也是零。

## 协议与资源证据

- `skill.dsh` 的已验证语义分类中，目标指向 `1` 且正生命变化、效果不为复活的共有 5 条，
  “清风拂体”是其中之一；见 `scripts/verify-battle-skill-catalog.php`。
- 既有 IDA 记录：`mmBattleMstarWqvga.cbm:HandleBattleActionMsg(0x6EB0)` 读取服务端
  actioninfo child 的目标槽和 `valueA`。对友方治疗，正 `valueA` 是回复量，客户端不会
  从技能名称或本地 HP 另行推导数值。
- 既有 `2026-08-08-battle-skill-effect-audit.md` 已确认：方向 `1` 的技能应使用原始
  `4/2.index` 选择友方，不得进入怪物目标转换；单人时该友方集合自然只包含施法者。

## 修复与覆盖范围

单人单体治疗改为对施法者执行与队伍相同的治疗公式：

```text
治疗量 = 技能正生命变化 + 力量/敏捷/智慧系数
实际治疗 = min(治疗量, 最大 HP - 当前 HP)
```

并把该准确正值同时写入战斗权威 HP 与 `4/6.actioninfo`。单人复活不改：死亡角色不能在
自己的回合施放复活，仍保持零变化的安全动作。

已逐类核对全部 74 条资源技能：

| 分类 | 数量 | 本次结论 |
| --- | ---: | --- |
| 单体治疗 | 5 | 修复单人自疗；队伍指定友方原已正确。 |
| 群体治疗 | 3 | 已按所有存活友方逐项结算，单人也会回复自己。 |
| 自身增益 | 22 | 正确的零 HP 变化；实际为临时属性变化。 |
| 群体增益 | 4 | 正确的零 HP 变化；实际为临时属性变化。 |
| 单体复活 | 1 | 仅对死亡队友生效；单人不能自我施放。 |
