# 非战斗进商城购买后退出闪退

## 压缩结论

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 非战斗（多为地图 HP=0）进商城买复活石，退出后闪退；后续战斗确认可能无反应 | 服务端曾“插入再消费”`801`：客户端本地仍见石（幽灵），服务端已无行；且退出时 mmGame 若仍按 0 血重建会崩 | 地图死亡且非战斗确认链：买 `801` 扣费并直接满血，`14/3(seq=0)+1/1/14`，**不入库**；若仅在 shop-return 消费已有石，则下一拍场景轮询下发 `1/1/1 actorinfo` |

## 契约

- 战斗死亡买石：仍只回 `14/3`，保留石头给 `1/7/14`。
- 地图死亡买石：`14/3 + 1/1/14(actorinfo 满血)`，不写背包行（避免幽灵石导致下次 `result=1` 空消费）。
- shop-return WT6/1 保持 `resources + 30/2`，不塞登录 `actorinfo`。

## 验证

重启服务。地图 HP=0：

1. 进商城买 801 → 日志 `map_revived=1` / `resp=14/3+1/1/14`，背包无新增 801 → 再退出不闪退。
2. 已有石、未再买就退出 → `mock_shop_return_map_revival` 后可见 `map_actor_vitals_sync`。
3. 再进战斗死亡：无幽灵石时应提示进商城，或有权威石时确认能出战。
