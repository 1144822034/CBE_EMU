# Pixi 停止挂机仍提示「挂机已启动」

## 现象

开始挂机、再点停止（或「下一场后停止」）聊天都出现 `[挂] 挂机已启动`。

## 根因

`parseHangupNotice` 把任意 `25/12` 硬编码成「挂机已启动」。  
`25/12` 是信息栏清除 ACK（`docs/re` / mock：`info-banner clear`），开始与停止应答里都会带，与挂机启停文案无关。

真实启停文案走 `1/3/3` 系统聊天：`已开始挂机` / `已停止挂机` / `下一场完成后挂机停止`。

## 修改

- 不再把 `25/12` 当成挂机提示；仅解析带 `info` 的 `25/11`。
- 从系统聊天同步 `hangupActive`，并把挂机相关系统句显示为 `[挂] …`。

## 验证

1. 点挂机 → `[挂] 已开始挂机`（不应再出现硬编码「挂机已启动」）。
2. 再点挂机 → `[挂] 下一场完成后挂机停止` 或 `[挂] 已停止挂机`。
