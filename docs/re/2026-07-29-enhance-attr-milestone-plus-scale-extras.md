# 强化附加：里程碑后追加护甲/攻击/生命/法力（2026-07-29）

## 需求

在现有 `+4/+8/+12/+16` 四条里程碑后面，再显示强化对
**护甲 / 物攻** 的加成（仅 `equip.dsh` 原值 > 0 的列）。气血 / 法力不再走 M(L) 基础强化行。

## 客户端边界

`ParseEquipAttributes` 写入物品块时 `cmp #6` / `blo`：词条下标 **0..5**，
最多 **6** 条。超过会写爆。

因此：`4 里程碑 + 4 列加成` 无法同时下满；实现为里程碑优先，剩余槽按
`护甲 → 物攻 → 气血 → 法力` 追加。

## Wire

`vm_net_mock_seq_put_item_common_extra`：

| 条件 | 内容 |
| --- | --- |
| `L>=4` | 部位模板 4 槽，unlock 4/8/12/16 |
| `L>=1` | 追加 `value = M(L)-base`，`unlock=1`，`flag=0`，仅 base>0 |
| 合计 | `attr_count ≤ 6`；second i16 高字节 = `attr_count` |

`M(L) = 1 + (10*L + 35*⌊L/4⌋)/100`（与穿戴汇总相同）。

## 显示含义

- `1<=L<4`：无里程碑，可显示最多 4 条基值加成（全亮）。
- `L>=4`：前 4 行里程碑（灰/亮按 unlock）；其后最多 2 行基值加成（亮）。

## 验证

- [ ] 武器（通常仅物攻>0）：+4 起 = 4 里程碑 + 物攻加成一行。
- [ ] 衣服（气血/法力等）：+1 即见对应加成；+4 起里程碑在前，加成在后。
- [ ] 四列基值都 >0 的装：+4 后只见护甲+物攻两行追加（气血/法力被容量截断）。
