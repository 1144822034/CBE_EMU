# 后台账号管理在线玩家统计（2026-08-27）

## 口径

“账号管理”中的在线玩家数来自当前服务进程的游戏会话链表，不查询或估算 MySQL
账号总数。仅当会话同时满足以下条件时计数：

1. `roleOnline` 已由既有角色上线生命周期置位；
2. 已绑定非空账号；
3. 具有非零持久 `onlineRoleId`。

因此，尚未进入角色的连接、已经执行离线生命周期的会话，以及不再绑定账号的旧会话
都不会计入。账号单点登录仍由既有接管路径维护，所以这个数表示当前在线角色/玩家数，
而不是某个页面已加载的账号行数。

## 页面与接口

账号管理左侧目录在账号总数下方显示“在线玩家”。初始 HTML 直接携带当前快照；浏览器
随后每 10 秒请求已认证的只读接口：

```text
GET /<admin-base>/online-players
{"online_players": <count>}
```

接口在后台 Cookie 验证之后才可访问，响应禁止缓存。刷新失败时保留最后一次成功的值并以
页面状态提示，不会影响账号目录、会话或游戏协议。

## 验证

`scripts/admin-request-length-regression.c` 构造两个已上线角色、一个离线角色和一个未绑定
角色，断言只统计前两个；同时断言后台脚本与接口路径保持一致。
