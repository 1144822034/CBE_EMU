# 副本地图右上角倒计时（2026-08-03）

## 运行时观察（用户观感）

进梦境/FB 图右上角显示 `08:05`，约 1 墙钟分钟后变为 `08:04`。

## 权威契约（复现 #9–#12）

| 项 | 结论 |
|----|------|
| 显示格式 | **MM:SS**（paint flags `f64/f68/f6c=0/1/1`，藏小时） |
| 权威剩余 | timer 对象 `+0x10`，单位 **秒**（例：`29285` = 8:08:05 → 屏 `08:05`） |
| 递减 | 客户端本地 tick，`remain--`；本局阈值 **≈60s/次**（非 1s） |
| 冒号闪烁 | paint 内独立 1000ms：`now-[obj+0x14]` 与 `1000` 比较，写 `obj+0x18`；**与 remain 无关** |
| 写死初值 | host poke `remain=60` → 屏 **01:00**（MM:SS）；每次进 `29*` 重置 poke，再进也会锁回 60 |
| 服务端语义 | **60 分钟**墙钟 TTL（默认）；到期 poll 投递使者出口出本 |
| TTL 配置 | 固定默认 `3600000`；可选 `JHOnlineData/dream_hud_ttl_ms.txt`（**不用环境变量**） |
| 多角色 | TTL 挂在 `client_session`，并绑定 `dreamHudTtlRoleId`；换角/离线清计时，互不继承 |
| 单位对照 | 客户端按「秒」字段运算；因 ~1 单位/墙钟分钟，`remain=60` ⇔ 服务端 60 分 |
| 服务端 | 进本请求流无 timer 包；`27/3`/`27/4` 探针无效 |
| 初值来源 | **unresolved**（未抓到 `29285` 的首次写入） |

用户观感「像 8 小时 5 分、末位每分钟变」与契约兼容：小时藏在 remain 里；60s tick 使秒个位约每分钟减一。
