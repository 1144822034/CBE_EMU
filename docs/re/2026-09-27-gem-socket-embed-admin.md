# 宝石镶嵌后台开关

日期: 2026-09-27

## 需求

管理后台可开启/关闭「+16 穿戴装备镶嵌宝石」；关闭时客户端隐藏装备栏「镶嵌」，服务端拒绝 29/17。

## 实现

### 配置

- 表 `server_gem_config` 新增列 `socket_embed_enabled`（TINYINT，默认 1）。
- 启动/保存时 `ensure_column` 自动补列。
- 后台 Tab「宝石配置」：下拉「允许镶嵌（+16 装备）」。
- 保存：`vm_net_mock_gem_config_admin_save(..., socketEmbedEnabled)`。

### 关闭时契约

| 路径 | 关闭后 |
|------|--------|
| 装备栏 +16「镶嵌」 | 不显示 |
| 装备详细页宝石词条（反伤/连击/复活） | 不显示 |
| 29/17 镶嵌 | 拒：`result=7`，`message=宝石镶嵌未开放` |
| 「拆宝石」/ 合成 / 兑换 | 不受影响 |

人物面板 `1/1/21` 下发 `gemSocketEnabled`；旧包缺字段时客户端按开。

## 验证

1. 后台「宝石配置」→ 镶嵌关 → 保存；拉面板后 +16 装备无「镶嵌」、详情无反伤/连击/复活行；强发 29/17 得 result=7
2. 开回 → 出现「镶嵌」与宝石词条且可镶
3. 关闭时已镶嵌装备仍可拆宝石（详情不显示词条，操作菜单仍有「拆宝石」）
