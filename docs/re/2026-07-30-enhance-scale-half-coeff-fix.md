# 强化 M(L) 系数半量修正（2026-07-30）

## 触发 / 偏离

文档与客户端累加表约定 `+16 → 4× base`（普通级 +10%、里程碑级 +45%），
但 `vm_net_mock_equipment_bonus_scale` 误用半量系数
`5L + 15⌊L/4⌋`，实际只有 **2.4×**（例：基攻 349 → 837，应为 1396）。

## 根因

实现与契约不一致：累加表 `12×10 + 4×45 = 300` 对应

```text
M(L) = 1 + (10*L + 35*floor(L/4)) / 100
```

代码写成了 `5` / `15`。

## 修改

`mock_server_catalog.c`：`bonusPct = 10*L + 35*⌊L/4⌋`；相关 `docs/re` 公式同步。

## 验证

- 349@+16 → `349 + 349×300/100 = 1396`
- `make -j2`
