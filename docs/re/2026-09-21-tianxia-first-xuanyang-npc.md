# 宣阳广场「天下第一」雕像（70 大乱斗冠军）

日期：2026-09-21  
范围：服务端 mock + **仅 PixiJS** 客户端表现；CBE 不特判放大/称号。

## 需求

- 根据最近一次 **70 大乱斗**（`server_arena_titles`：`job=0, bracket=77, place=1`）第一名，在 **临安-宣阳广场**（`c04临安府_10`）生成 NPC 雕像。
- 形象：角色当前职业/性别对应 `h_*/hW_*.actor`；Pixi 身体放大 **2×**，名字上方文字称号 **天下第一**。
- 完成当日跑环（`ring_count >= daily_max`，默认 20）的玩家每天可交互 **1** 次，选项「膜拜大侠」。
- 若交互者即冠军本人：每天 **3** 次，选项「接受膜拜」，无跑环前提；另有选项「江湖签名」。
- 江湖签名：冠军输入最多 **32** 字，显示为雕像对话框主文。未输入（或后台清空）显示  
  `这个冠军很高冷,什么也没说!`。管理后台「江湖签名」可维护同一字段。
- 交互等价开一次黄金宝箱（524）奖池（含保底），不消耗箱/钥匙；需播报物品时文案为  
  `和江湖第一高手交流意外收获{物品名}`（替换原「开启黄金宝箱」句式）。

| Pixi | `ActorLayer` 2× scale + 雕像吃 `31/5`；常量 `protocolActivities.ts` |

## 管理后台（比武页）

`/?tab=arena` →「天下第一雕像」：

| 项 | 说明 |
|---|---|
| 启用 | 关闭则广场不刷雕像 |
| 坐标 X/Y | 宣阳广场像素坐标 |
| 放大×100 | 200=2 倍（50–400） |
| 头顶文字 | 名字上方文字，不限于「天下第一」 |
| 交互选项 | 其他人 / 冠军本人 |
| 江湖签名 | ≤32 字；空则对话框显示「这个冠军很高冷,什么也没说!」 |
| 显示翅膀/动态称号/坐骑 | 取冠军当前装备；动态称号未装备时显示角色当前称号 |
| 朝向 | 面朝左（CBE dir=4） |

配置表：`server_tianxia_statue_config`。Pixi 经 NPC `scriptName`（`pixi_tx1|scale|wing|chenghao|mount|titleHex|playerTitleHex|plus16`）读缩放、特效与脚底 +16 光环环数。

## 验证

1. 大乱斗结算出第一名后进宣阳广场：雕像名为冠军、放大、面朝左，头顶为后台文字；冠军有 +16 装备时脚底显示对应环数强化光环。
2. 后台改坐标/倍数/文案 → 保存 → 重进宣阳广场生效。
3. 打开「显示翅膀」且冠军有翅 → 雕像带翅膀。打开「显示动态称号」：有动态称号则显示动态称号，否则显示角色当前称号。坐骑同理。冠军本人切换翅膀/动态称号后，宣阳广场内雕像应跟着变（无需重进图）；离线改装后下次进广场也读最新值。
4. 未满环：膜拜被拒；满环：成功一次，背包+奖池物品。
5. 冠军本人：三次「接受膜拜」，无满环要求；另有「江湖签名」。
6. 签名：输入后雕像对话框主文变为该句；留空或后台清空后显示「这个冠军很高冷,什么也没说!」。
7. 稀有掉落世界频道为「和江湖第一高手交流意外收获…」。
