# Pixi 战斗已选仙术/物品超时仍普攻

日期：2026-08-08（修订 2026-09-14）

## 触发与现象

回合倒计时到 0 后只显示「超时·普攻」，或停在选目标，没有发出 `4/2` 普通攻击。

另：已打开仙术/物品、具备使用条件时超时仍普攻（见下文修订）。

## 根因（2026-08-08）

超时回调调用了手动菜单用的 `attack()`。该路径在存活敌人 **>1** 时走 `beginTargetPick`，**不提交** operate。  
计时器已把 `timerSec` 置 0，不会再触发，座位卡在选目标 / 空操作。

契约（`2026-08-06-pixijs-battle-scene.md`）：根菜单停手超时应默认普攻。

## 修改（2026-08-08）

`BattleScreen.submitTimeoutAttack()`：倒计时到期时固定选首个存活敌（若已在普攻选目标则用当前光标），直接 `noteOperateSubmitted` + `onAttack`，不进选目标 UI。

## 修订（2026-09-14）

上一版把**任意**超时都打成普攻，连「已选仙术/物品」也清空 pending。详见
`2026-09-14-pixi-battle-skill-item-timeout-na.md`：选目标中的仙术/物品、列表光标上的可用行改为提交所选；仅根菜单 / 普攻选目标仍默认普攻。

## 验证

1. 单怪：根菜单停手至超时 → 自动普攻并播 `4/6`。
2. 多怪：根菜单停手至超时 → 直接打第一个存活怪，不出现选目标菜单。
3. 已在「攻击→选目标」时超时 → 用当前光标目标提交普攻。
4. 已在「仙术/物品→选目标」时超时 → 提交该仙术/物品（非普攻）。
