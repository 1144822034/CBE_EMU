# 战斗倒计时结束未提交默认普攻

日期：2026-08-08

## 触发与现象

回合倒计时到 0 后只显示「超时·普攻」，或停在选目标，没有发出 `4/2` 普通攻击。

## 根因

超时回调调用了手动菜单用的 `attack()`。该路径在存活敌人 **>1** 时走 `beginTargetPick`，**不提交** operate。  
计时器已把 `timerSec` 置 0，不会再触发，座位卡在选目标 / 空操作。

契约（`2026-08-06-pixijs-battle-scene.md`）：超时应默认普攻。

## 修改

`BattleScreen.submitTimeoutAttack()`：倒计时到期时固定选首个存活敌（若已在普攻选目标则用当前光标），直接 `noteOperateSubmitted` + `onAttack`，不进选目标 UI。

## 验证

1. 单怪：停手至超时 → 自动普攻并播 `4/6`。
2. 多怪：停手至超时 → 直接打第一个存活怪，不出现选目标菜单。
3. 已在「攻击→选目标」时超时 → 用当前光标目标提交普攻。
