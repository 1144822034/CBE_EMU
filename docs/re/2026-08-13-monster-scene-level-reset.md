# 怪物批量按场景等级重置

## 权威来源

`automonster.dsh` 仅定义“场景 -> 自动刷怪 ID”，没有等级列。`sMap.dsh` 的
最后一列“怪物等级”才是每个 `.sce` 场景的原始等级信息，值可以是单级或范围。

## 后台批量操作

怪物管理的“按场景等级重置”对已选择的怪物执行一次 MySQL 事务：

1. 普通怪取 `automonster.dsh` 的首个自动出生场景；SCE 专属战斗怪取其首个
   解析到的战斗场景。
2. 从对应 `sMap.dsh` 行取怪物等级；范围使用向上取整的中位数。
3. 覆盖怪物等级，并按该等级和现有类型重算 HP、MP、攻击、防御、战斗经验和铜钱。
4. 保留类型和掉落；首次生成覆盖时将原有默认掉落写入数据库。

没有 `sMap` 怪物等级的城镇、任务专属或未映射场景不会猜测等级，会被跳过并在
操作结果中报告。
