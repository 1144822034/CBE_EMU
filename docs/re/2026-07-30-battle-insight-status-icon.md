# 战斗心得左上角状态图标

日期：2026-07-30

## 触发与现象

使用 828 战斗心得后，经验加成/自动修装已生效，但左上角不显示状态图标。

## 根因

客户端图标由同一套路径驱动（`JianghuOL.CBE:0x01011AF8` / `0x01011A5E`）：

1. `expcard != 0`（`7/30` 本地写，或服务端 `7/32`）
2. 非空 `7/31 {expinfo}`（决定是否 `strb` 图标可见标志并画 tip）

经验卡：`7/30` 成功后附带 `7/31`。  
战斗心得：`1/25/6` → `1/25/7`，此前只回专用对象，**从不**下发 `7/31`/`7/32`，故图标槽保持关闭。

## 修改

- `7/31 expinfo`：心得激活时推送「战斗心得生效中(剩余XhYm / N分钟)」；与经验卡共用槽，两者同时激活时优先经验卡文案。
- 使用成功 `25/6` `iteminfo`：`战斗心得效果已生效，经验增加20%(剩余…)。`（叠加后读墙钟剩余）。
- 使用成功 `25/6` / follow-up `25/7`：附加 `7/32{expcard=1}+7/31`（与自定义经验卡 `7/1` 臂装相同）。
- 登录 `7/7 type=3`、场景 sync、`7/31` 状态查询、actorinfo/`7/32` 的 `expcard` 字段：心得激活时同样视为 status icon 打开。

战斗结算仍用独立的 insight percent / card multiplier，不因 UI `expcard` 标志改变倍率。

## 验证

1. 重启服务端，使用 828：日志含 `mock_special_item_use ... 25/6` 与 `mock_battle_insight_followup ... status_objs=2`。
2. 使用成功弹窗含「剩余」；左上角 tip 含「战斗心得生效中(剩余…)」。
3. 叠加第二张后剩余约 +60 分钟。
4. 仅心得、无经验卡时重登后图标仍在。
5. 心得与经验卡同时存在时显示经验卡 tip（心得战斗加成仍生效）。
