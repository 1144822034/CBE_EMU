# 恩怨页 + 江湖追杀令（2026-08-12）

## 需求

1. 好友列表增加「恩怨」标签：显示自己击杀的玩家、击杀自己的玩家，以及击杀次数。
2. 商城增加「江湖追杀令」（道具 id=847，耐久 1）：对仇人使用可显示其所在地图名并扣除耐久；若对方离线则不扣除。

## 协议（Pixi-only WT kind=43）

| subtype | 方向 | 字段 |
| --- | --- | --- |
| 1 page | C→S | `dir` 0=我击杀 / 1=击杀我，`index`，`pageSize` |
| 1 page | S→C | `allpgs`，`dir`，`enmityinfo`（i16 count + {u32 id,string name,u8 online,u32 kills}×N） |
| 2 hunt | C→S | `itemId`，`seq`，`targetId` |
| 2 hunt | S→C | `result`，`remaining`，`tip`（GBK） |

离线：`result=0`，tip「对方不在线」，**不扣**背包。在线且为仇人：扣 1 耐久，tip「仇人当前在」+ 地图显示名。

## 数据

表 `enmity_kills`（见 `server/mysql/migrate_add_enmity_kills.sql`）。普通切磋终端结算时，在 `vm_mock_service_duel_arm_both_exits` 之后按单方 HP=0 记一笔。**擂台 / 赌战不计。**

## 道具

- id **847**，分类 10，耐久 1（背包 `count`），商城默认上架酷宝价 50。
- 通用 `7/1` 拒绝并提示「请选择仇人使用」（不扣）；真正使用走 `43/2`。

## 客户端

- `SocialPanel`：好友顶栏 `[好友|恩怨]`，恩怨下 `[我击杀|击杀我]`。
- 背包对 847「使用」→ 打开恩怨「击杀我」选目标 → `useHuntOrder`。
- 好友/恩怨服务端分页：每页 10 条；列表底/顶再按 ↑↓ 请求上一页/下一页（`allpgs`）。
