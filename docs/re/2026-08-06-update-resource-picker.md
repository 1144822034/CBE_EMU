# 具名资源发布：后缀分类与名称搜索

## 契约

“游戏内容更新管理 → 具名资源发布”不再把服务器资源目录直接作为下拉框展示。
页面仍从服务端资源目录生成同一份受限资源选项；浏览器将其映射为选择弹窗，并按
文件名最后一个后缀动态建立分类（例如 `.sce`、`.xse`、`.actor`、`.gif`、`.map`
和 `.cbm`）。管理员可叠加后缀分类与不区分大小写的名称搜索，再点击一项选择。

提交时字段仍为原有 `resource=<资源名>` 和 `version=<版本>`，由现有
`publish-named-update` 处理器校验及保存。弹窗没有新增资源来源、上传路径或下载
能力；选择为空时会阻止表单提交并明确提示。

## 验证

打开更新管理页，确认“选择资源”弹窗可以：

- 显示资源总数；
- 仅展示所选后缀，例如 `.actor`；
- 进一步按名称片段过滤；
- 点击资源后将名称写回发布表单，并能按原有流程提交。
