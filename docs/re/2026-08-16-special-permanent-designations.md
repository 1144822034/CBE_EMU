## 全套契约

`equip.dsh` 类别：`0` 帽 … `6` 饰，`7/8/9` 剑/匕/杖。

**全套**定义为：

1. 防具类别 **1–6**：每一类至少穿戴同套一件（同类别可有多件变体时任选一件）；
2. 武器类别 **7/8/9**：任意一件。

实现细节：

- 圣诞套 ID `40020`–`40029`：武器必须来自该套（三选一）。
- 武林套 ID `40150`–`40159`：防具 1–6 + 武林武器三选一（40150/40151/40152）。
- 类别 `0`（帽）不计入本「全套」门槛（与需求「1–6」一致）；帽仍可穿戴，但不作为激活条件。

## 持久化

- `account_roles.special_designation_mask`：bit0=41 … bit4=45；只置位不清除。
- `UNIX_TIMESTAMP(created_at)` 载入 `role.createdAtUnix`；门槛 `1786809600`（2026-08-16 00:00:00 Asia/Shanghai）。
- 换装成功 / 打开称号页 / `role_normalize` 时 `refresh_special_designations`。

## 验证

1. 穿齐圣诞防具 1–6 + 任一圣诞武器 → 称号页出现圣诞骑士；卸装后仍在。
2. 穿齐武林防具 1–6 + 任一武林武器（40150/40151/40152）→ 武林传奇永久解锁。
3. 2026-08-16 前创建的角色登录即见资深老友；再穿梦境武器得勇者王与资深老友勇者王。
4. 新角色（创建时间 ≥ 门槛）不得解锁资深类。
