# server_monsters 等级对齐 sMap.dsh

日期：2026-08-09

## 原因

世界地图 / 区域地图等级来自 `wMap.dsh` / `sMap.dsh`（如丹霞山 `12~15级`），但 `server_monsters.level` 仍是旧 builtin 低等级（饿虎/掘地鼠/染血骷髅 3~5）。名牌与开战覆盖以 MySQL 为准时会偏矮。

## 掉落（server_monster_drops）

**未改动、无需互换。** 抽查丹霞等图：装备掉落已是地图档次（约 12~15 的布甲/短剑等），与 sMap 一致；需要同步的是等级与战斗基数，不是掉落行对调。

## 修改

- 更新 `server_monsters` 行数：72
- 新等级 = 怪物首次场景在 `sMap.dsh` 的等级（`A~B级` 取中值）
- 同步按 family 公式重算 hp/mp/attack/defense/exp/money 基数（与 `vm_net_mock_monster_base_stats_for_enemy` 一致）
- `server_monster_drops`：保持原样
- `server_monster_catalog_extra.level`：有行则一并更新

| ID | 场景 | 旧等级 | 新等级 (sMap) |

| 9 | 03丹霞山_02.sce | 3 | 13 (13级) |
| 77 | 03丹霞山_03.sce | 5 | 15 (15级) |

## 验证

- 重启 `jh-online-server`（`monster_db_load` 只在启动时装载）
- 重启 gateway 后刷新 Pixi：丹霞山名牌应为 12/13/15 级档
- 世界地图仍显示 sMap/wMap 原文案（12~15级）
