# 怪物品质 0 装备参照属性曲线（2026-08-10）

## 触发与首个偏离

怪物管理与战斗入口都经 `vm_net_mock_monster_stats_for_enemy()` 读取四项属性。本机
`jh_online.server_monsters` 只有少数显式管理员覆盖，因此多数怪物使用默认曲线。

默认曲线原先以“同等级、最低职业、无装备”角色为基准，再通过随等级增长的装备时代倍率
补偿真实玩家的装备。实际战斗的玩家属性却直接将 `equip.dsh` 的装备属性完整计入，因而该
倍率与装备补偿属于两层不同来源的重复估算。首个偏离在服务端默认数值模型，不在客户端
解析、场景怪物节点或战斗下行包。

## 已确认的数据来源

- `JHOnlineData/equip.dsh` 有 1485 件装备，其中品质 0 共 432 件；八个装备槽位在 1～70
  级都有可用的品质 0 候选，低等级尚未开放的槽位保持为空。
- `automonster.dsh` 只提供场景与三个怪物 ID 的对应关系；它不含 HP、MP、攻击或防御。
- `server_monsters` 仍是显式管理员覆盖。该表中已有数值不被这次默认曲线更新覆盖；使用
  “仅重置 HP/MP/攻击/防御”时才会按当前等级和种类重新生成四项属性。

## 当前契约

默认曲线构造三个同等级角色（剑、匕首、杖），每一槽严格从 `equip.dsh` 选择：

1. 品质必须为 0；
2. 需求等级不得高于怪物等级；
3. 选取需求等级最高的候选；同等级时武器按物攻、其他槽按护甲择高，再以物品 ID 稳定决胜；
4. 武器必须匹配职业类别（剑/匕首/杖）；
5. 以三职业每项中的最低 HP、MP、攻击、防御作为普通怪与首领的共同保守参照。

完整角色属性仍由 `vm_net_mock_role_build_player_stats_impl()` 计算，因此属性、耐久与装备
目录的语义与实际战斗一致。原“装备时代”二次倍率已经删除；品质 0 装备本身就是唯一的
装备参照。随后仅套用既有怪物种类倍率；首领以更高的基础 HP/攻击/防御形成需要协作的
属性难度，不设人为组队准入限制。

回归锁定的参照值为：

| 等级 | HP | MP | 攻击 | 防御 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 120 | 100 | 26 | 8 |
| 60 | 2234 | 1555 | 425 | 3588 |
| 70 | 3496 | 2253 | 791 | 5026 |

这些是本项目选择的平衡政策，不声称为未恢复的原服公式。

## 验证与边界

- 回归：`tmp/monster-level-scaling-regression.c` 会加载真实 `equip.dsh`，验证等级 1、60、70
  的品质 0 基准、史莱姆、亡灵单调性和 70 级普通/首领轮廓。
- 构建：`make -j2`。
- `1/2/2` 场景节点 seed、`1/4/5` 开战和 `1/4/6` 伤害路径继续使用统一的
  `vm_net_mock_monster_stats_for_enemy()`，未修改客户端或伪造客户端状态。
