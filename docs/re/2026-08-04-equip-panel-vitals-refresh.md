# 2026-08-04 穿戴后属性/生命/护甲与法力%

## 现象（第二轮）

1. 装备力量、护甲面板不加  
2. 裸装法力 928；+12 档详情显示法力 **+232%**（应为 +25%）；战斗/HUD 法力仍偏高  
3. 卸下后装备槽仍显示该件，背包也有一份

## 根因

### A. 法力% wire 误改定值（本轮引入）

客户端 `0x0100FED8` 先把当前气血/法力池写入栈，词条循环后对 `flag!=0` 做

```text
加成 = 当前池 * wireValue / 100
```

详情 `flag!=0` 画 `%`。把品质4的 25 改成定值 232 后：详情 +232%，apply 按 928×232/100。

正确契约：wire 仍发 **百分数 25**；服务端 `collect` 用人物基础池×% 计入 `equipment.mp`。

### B. 换装响应追加 `7/7 type=2`

`7/8` 已由客户端搬槽并 wear-apply。再追加登录用 `7/7 type=2`（`+104`/`r2=-1`）会**再插入**穿戴行：卸下后槽位残留 + 背包一份，且百分比叠算。

### C. `maxMp` 与客户端 percent 池不一致（第三轮：1759 vs 1908）

客户端最终：`(裸 + 定值) * (100 + pctSum) / 100`。  
旧服务端：`裸 + 定值 + 裸 * pctSum / 100` → 少 `定值 * pct / 100`（Δ149）。

另：`maxMp` 不得用装备后 `wisdom`（帽子智慧×3）。

## 修复

| 点 | 变更 |
| --- | --- |
| `collect_equipment_bonus` | 定值入账后 `(裸+定值)×percentSum/100` |
| `build_player_stats` | `maxMp` 用 `baseWisdom` |
| `mock_item_equip` | 无登录 `7/7` 重插；保留 vitals arm |
| `build_actor_info` | word[0]/[1]/[3] 满力量/敏捷/智慧 |
| `mock_item_equip` / swap | 同包 live 子集 `+1/1/14`；无登录 `7/7` 重插 |

见 `2026-08-04-equip-primary-attr-refresh.md`（含 live 字段表与物攻 FA）。

## 验证

1. +12 品质4：详情法力 **+25%**（不是 +232%）  
2. 裸装 928 → 穿戴后法力约 `928 + 928*25/100`（及装备法力列），与战斗同量级  
3. 卸下：槽空、背包一件  
4. 上衣/披风/帽子 +16：力/敏/智随穿脱刷新  
5. `make -j2`
